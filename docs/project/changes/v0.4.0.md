## 1. Рефакторинг `manage_samples_view`

### Цель

Текущий файл `dasmixer/gui/views/manage_samples_view.py` содержал >800 строк, совмещая несколько несвязанных ответственностей. Превращён в Python-пакет.

### Новая структура пакета

```
dasmixer/gui/views/manage_samples_view/
├── __init__.py                  # реэкспорт ManageSamplesView
├── manage_samples_view.py       # тонкий оркестратор (ft.View)
├── data_manager.py              # SampleDataManager — кэш статистики, загрузка, drop_empty_files
├── update_row.py                # UpdateRow — кнопка Update + ProgressRing + поля порогов
├── sample_panel.py              # SampleViewPanel — панель образца с чекбоксом и телом
├── mass_operations_row.py       # MassOperationsRow — кнопки массовых операций
└── dialogs/
    ├── __init__.py
    ├── drop_file_dialog.py      # DropFileDialog — 2-этапный: тип удаления → подтверждение
    └── assign_subset_dialog.py  # AssignSubsetDialog — dropdown групп → Assign
```

### Архитектурные решения

- **`SampleDataManager`** — отдельный класс, инкапсулирующий все операции с кэшем. Методы: `load_all`, `refresh_single`, `refresh_all_fresh`, `drop_empty_files`, `get_sample_detail`
- **`UpdateRow`** — самостоятельный Flet-компонент с публичными методами `set_loading(visible)` и `get_thresholds()`
- **`SampleViewPanel`** — принимает `on_action` callback (диспетчеризация через `ManageSamplesView`) и `on_selection_changed` для чекбокса
- **`ManageSamplesView`** — тонкий оркестратор без собственной логики построения UI, только композиция компонентов и диспетчеризация

## 2. Массовые операции с образцами

### 2.1 Чекбокс в заголовке панели

- В `SampleViewPanel` добавлен `ft.Checkbox` в **начало** строки заголовка — левее иконки статуса
- Виден всегда (свёрнута/развёрнута панель)
- При изменении вызывает `on_selection_changed(sample_id, selected)`
- `ManageSamplesView` ведёт `_selected_ids: set[int]`

### 2.2 Строка MassOperationsRow

Расположена между `UpdateRow` и `ExpansionPanelList`. Содержит 3 группы кнопок, разделённых `ft.VerticalDivider`:

```
[Select All] [Deselect All] | [Outlier] [Drop file] [Assign group] [Delete] | [Drop empty files]
```

- Все кнопки всегда видны
- При нажатии без выбора — snack «No samples selected»

### 2.3 Действия

| Действие | Диалог | Snack |
|---|---|---|
| **Select All** | Нет | Нет |
| **Deselect All** | Нет | Нет |
| **Outlier** | Нет (инвертирование) | «Outlier set/cleared for N sample(s)» |
| **Drop file** | 2 этапа: тип → подтверждение со списком | «Deleted N file(s)» |
| **Assign group** | Dropdown + Assign | «Group assigned for N sample(s)» |
| **Delete** | Inline список образцов + Confirm | «Deleted N sample(s)» |
| **Drop empty** | Нет | «Removed X spectra and Y idents» или «No empty files found» |

### 2.4 DropFileDialog — детали

**Первый диалог (выбор типа):**
- RadioGroup с 5 вариантами: `spectra_all`, `spectra_keep_first`, `spectra_keep_last`, `ident_all`, `ident_by_tool`
- Dropdown инструментов всегда виден, активен только при `ident_by_tool`

**Второй диалог (подтверждение):**
- Прокручиваемый `ListView` (height=200px)
- Строки: `[тип] ID=N  /последние/2/компонента/пути`
- Предупреждение: ⚠ «Source files on disk are not affected»

### 2.5 Drop empty files — детали

Прямые SQL-запросы:
```sql
SELECT id FROM identification_file WHERE NOT EXISTS
  (SELECT 1 FROM identification WHERE ident_file_id = identification_file.id)
SELECT id FROM spectre_file WHERE NOT EXISTS
  (SELECT 1 FROM spectre WHERE spectre_file_id = spectre_file.id)
```

## 3. On duplicates в импорте

### 3.1 Область применения

RadioGroup «On duplicates» добавлен **только** в `ImportPatternDialog`. `ImportSingleDialog` и `ImportStackedDialog` не затронуты.

### 3.2 Расположение

```
[parser / group dropdown]
─────────────────────────
On duplicates:
  ● Skip (default)
  ○ Reload
  ○ Add as new
─────────────────────────
[protein options, если есть]
[Preview Files]
[file list]
```

### 3.3 Режимы

| Режим | Spectra | Identifications |
|---|---|---|
| **skip** (default) | `continue` — не создавать файл | `continue` — не создавать файл |
| **reload** | `delete_spectra_file` (каскад) → создать заново | `delete_identification_file` → создать заново |
| **add_as_new** | Создать новый файл (дубликат разрешён) | Создать новый файл |

### 3.4 Новые API-методы

#### `SpectraMixin.get_spectra_file_by_path(path)`
```python
async def get_spectra_file_by_path(self, path: str) -> dict | None:
    row = await self._fetchone(
        "SELECT * FROM spectre_file WHERE path = ?", (path,))
    return dict(row) if row else None
```

#### `IdentificationMixin.get_identification_file_by_path(file_path)`
```python
async def get_identification_file_by_path(self, file_path: str) -> dict | None:
    row = await self._fetchone(
        "SELECT * FROM identification_file WHERE file_path = ?", (file_path,))
    return dict(row) if row else None
```

### 3.5 Snack при skip

После завершения цикла импорта, если `skipped_count > 0`:
```
show_snack(page, f"{skipped_count} file(s) skipped (already imported)", ft.Colors.ORANGE_400)
```
