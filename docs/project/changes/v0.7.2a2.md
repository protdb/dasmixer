# v0.7.2a2

**Date:** 2026-09-01

---

## New Features

### Unconfirmed PTMs

- Показатель **Unconfirmed PTMs** — количество PTM в последовательности, не подтверждённых ни одним совпавшим фрагментным ионом (`seq_ptms - max_frag_ptm`). Целое число `>= 0`; для последовательностей без PTM возвращается `0`. Расчёт — на основе функций `calculate_unconfirmed_ptms` / `_get_ptm_amount` в `quality_calculations.py`, значение уже возвращается полем `MatchResult.unconfirmed_ptms` из `match_predictions` (реализация — в 0.7.1).
- **Max Unconfirmed PTMs** (по умолчанию `0`) — новый параметр Preferred settings инструмента. В отличие от `min_quality`/`min_lcrr` (больше — лучше, `>=`), для `unconfirmed_ptms` используется инвертированная семантика: **`<=`** (чем меньше — тем лучше). Фильтрует кандидатов в Select Preferred: идентификации с `unconfirmed_ptms > Max Unconfirmed PTMs` (или без вычисленного значения) не выбираются preferred через normal-пул; trusted-пул (`Trust all identifications`) игнорирует этот порог, как и все остальные.
- При Clear Calculations поле `unconfirmed_ptms` сбрасывается в NULL наравне с остальными расчётными полями.

### Peptide Table

- Новая колонка **Unconfirmed PTMs** доступна в таблице Peptide Identifications, но **скрыта по умолчанию** (в отличие от LCRR, которая видна сразу). Колонку можно показать через стандартный gear-диалог выбора столбцов.

### Peptide ion plot

- Установлен новый механизм расчёта размера графика при нескольких тображаемых последоватлеьностях

### BasePlotView

- Графики в интерактивном режим отображаются в том же размере, что и в GUI
- Окно интерактивного режима в WebView отображается в максимально доступном размере (выбор между размером окна dasmixer и размером графика)


### Joined Peptide Data — рефакторинг и новые фильтры

- Методы `get_joined_peptide_data`, `count_joined_peptide_data` и `_build_peptide_filter_conditions` вынесены из `PeptideMixin` в новый миксин `JoinedPeptideDataMixin` (`joined_peptide_data_mixin.py`) для улучшения структуры кода.
- Добавлен GUI-фильтр **Sequence Identified** (выпадающий список Yes/No/All, аналогичный Protein Identified) — отфильтровывает идентификации с NULL-последовательностью.

### Bug Fixes

- **Spectre ID filter:** исправлен баг, из-за которого фильтр по Spectrum ID не работал. В `_build_peptide_filter_conditions` отсутствовал `params.append(spectre_id)` (SQL-условие `s.id = ?` добавлялось, но параметр не биндился). Дополнильно добавлен проброс `spectre_id` в kwargs в GUI-слое (`_build_filter_kwargs`).
- **Matched sequence отображение на Peptide Ion Plot View:** исправлен баг, из-за которого последовательности в белке не отображались при неполном совпадении (когда matched_sequence_modified отличается от sequence, но matched_sequence_modified не равен canonical_sequence). Исправлено сравнение — теперь сравнивается `matched_sequence_modified` с `sequence`, и в заголовок выводится `matched_sequence_modified` (с PTM-модификациями) вместо `matched_sequence`.
- Корректное отображение графиков спектра при отсутствии последовательности
