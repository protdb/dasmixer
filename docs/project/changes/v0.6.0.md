# v0.6.0

**Date:** 2026-06-24

---

## New Features

- **Portable Projects** — `save(checkpoint=True)` with WAL checkpoint truncation; `save_as()` now produces fully self-contained files; new `vacuum()` method.
- **GUI File menu expanded** — Save, Save As and Merge Project items (disabled when no project open).
- **Project Merge/Import** — new `ImportProjectMixin` with full 7-step merge of another `.dasmix` file (subsets, tools, samples, 10 data tables, settings); available via GUI (`MergeOptionsDialog`) and CLI (`import-project`).
- **CLI: `checkpoint` and `vacuum` commands**.
- **CLI: `tool` commands** — `add`, `configure`, `param-list`, `list` for managing project tools.
- **CLI: `project configure`** — set and list project settings.
- **CLI: `ident-file` and `ident-pattern`** — full implementation of identification import with spectra mapping.
- **CLI: `fasta` import** — FASTA file import with batch processing.
- **CLI: `calculate` commands** — `ion-coverage`, `preferred`, `peptide-match`, `protein-idents`, `lfq`, and `peptides` (full pipeline).
- **GUI: New/Open Project buttons** added to start view layout.
- **Windows support** — conditional `npysearch-win` dependency for Windows builds replacing custom windows .wheel via URL (crucial for PyPi installs)
- **Text selection in tables** — table cell text can now be selected.

## Bug Fixes

- **Jinja2 templates not bundled** — `.j2` files added to PyInstaller `datas` block.
- **Kaleido/Chrome wrong path** — `_find_chrome_exe()` replaces hardcoded platform directory name.
- **`npysearch` import error** — wrapped in `try/except ImportError` with a clear error message.
- **`NameError: name 'Path' is not defined`** in `settings_view.py:_apply_logging_config`.
- **`SampleViewPanel` dialogs not working** — `self.page` → `e.page` in all `on_click` handlers (8+ locations).
- **`ft.ElevatedButton("Delete", ...)` without `content`** — fixed in 3 places for Flet 0.80.5 API.
- **Ion coverage calculation incomplete** — fixed issue where ion coverage calculation did not run to completion.
- **Peptide mapping errors with identity < 1.0** — fixed incorrect peptide mapping when identity score is below 1.0.
