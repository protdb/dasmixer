### Задача 4 — CLI: реализация импорта идентификаций

**Изменён:** `dasmixer-cli/src/dasmixer/cli/commands/import_data.py`

Заглушки `ident-file` и `ident-pattern` заменены на полноценную реализацию:

- **`ident-file`** — импорт одного файла идентификаций:
  - Поиск образца по имени, инструмента по имени
  - Авто-определение `spectra_file_id` (первый файл образца) или явное указание
  - Получение парсера из `registry`
  - Создание `identification_file` в БД
  - Получение `spectra_idlist` для маппинга спектров
  - Пакетный парсинг файла с мержем по `spectra_id_field` → `spectre_id`
  - Вывод статистики (импортировано/совпало/не совпало)

- **`ident-pattern`** — паттерн-импорт (через `seek_files`):
  - Показ найденных файлов с подтверждением
  - Для каждого файла вызов `_import_ident_file_internal()`
  - Пакетный отчёт: `✓ Imported N files, M identifications total`

- **`_import_ident_file_internal()`** — общая async-функция для обеих команд

### Задача 5 — CLI: импорт FASTA

**Изменён:** `dasmixer-cli/src/dasmixer/cli/commands/import_data.py`

- Новая команда `import fasta`:
  - `--file / -f` — путь к FASTA (обязательный)
  - `--batch-size` — размер пачки (default 100)
  - Валидация через `FastaParser.validate()`
  - Пакетный импорт через `FastaParser.parse_batch(batch_size)`
  - Вывод статистики: всего белков, UniProt entries, Generic entries

### Задача 6 — CLI: команды расчётов (`calculate`)

**Новый файл:** `dasmixer-cli/src/dasmixer/cli/commands/calculate.py`
**Изменён:** `dasmixer-cli/src/dasmixer/cli/main.py`

Шесть команд, дублирующих кнопки GUI:

| Команда | GUI-аналог | Описание |
|---------|-----------|----------|
| `calculate ion-coverage` | Calculate Ion Coverage | Расчёт PPM/coverage. Настройки из `project_settings` + CLI-переопределение (`--tolerance`, `--ions`) |
| `calculate preferred` | Select Preferred | Выбор предпочтительных идентификаций. Параметры инструментов из `project_settings` |
| `calculate peptide-match` | Match Proteins to Identifications | Маппинг пептидов на белки через `map_proteins()` |
| `calculate protein-idents` | Calculate Protein Identifications | Поиск белковых идентификаций через `find_protein_identifications()` |
| `calculate lfq` | Calculate LFQ | Количественный анализ (emPAI, iBAQ, NSAF, Top3). Методы из флагов или `project_settings` |
| `calculate peptides` | (полный пайплайн) | Последовательно: peptide-match → ion-coverage → preferred |

Общий принцип:
1. Открытие проекта через `async with Project(...)`
2. Чтение настроек из `project_settings`
3. CLI-опции переопределяют настройки (если указаны)
4. Сохранение настроек обратно в `project_settings` (LFQ, protein-idents)
5. Вывод прогресса в stdout
6. Автосохранение через `project.save()`

### Задача 8 — GUI: аудит и исправление диалогов в manage_samples_view

**Изменены:** 4 файла

Корневая причина: `SampleViewPanel(ft.Container)` не добавляется напрямую в страницу (только его `_expansion_panel`), поэтому `self.page` всегда `None`.

| Файл | Изменения |
|------|-----------|
| `sample_panel.py` | 8+ обработчиков `on_click`: `self.page.run_task(...)` → `e.page.run_task(...)`, удалён `if self.page else None` |
| `manage_samples_view.py` | AppBar back button: `self.page` → `e.page`; Mass-delete Delete button: добавлен `content=ft.Text("Delete")` + `e.page` |
| `assign_subset_dialog.py` | Assign button: `self.page` → `e.page` |
| `drop_file_dialog.py` | Confirm и Delete button: `self.page` → `e.page`; Delete button: добавлен `content=ft.Text("Delete")` |

Правило: в `SampleViewPanel` — `e.page` (из Flet-события), в `ManageSamplesView(ft.View)` — `self.page` (корректно, т.к. View в дереве страницы).
