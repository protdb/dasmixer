## New Features

### Subplot заголовки — настраиваемые поля (Peptide Ion Plot)

Полностью переработана логика формирования заголовков subplot'ов в графике ионов. Пользователь теперь может выбирать, какие параметры отображаются в заголовке каждого subplot'а, через строку чекбоксов **Subplot Header Fields** в панели Plot Settings.

**Список полей и их состояние по умолчанию:**

| Поле | По умолчанию | Отображение |
|---|---|---|
| Preferred | ☑ | `★` (префикс) |
| Tool | ☑ | Название инструмента |
| Sequence | ☑ | Последовательность |
| Protein ID | ☐ | ID белка |
| Gene | ☐ | `Gene: {value}` |
| Identity | ☑ | `Identity: {value:.2f}` |
| PPM | ☐ | `PPM: {value:.2f}` |
| Score | ☐ | `Score: {value}` |
| Intensity Coverage | ☐ | `iC: {value:.2f}` |
| Quality | ☐ | `Q: {value:.2f}` |
| LCRR | ☐ | `LCRR: {value:.2f}` |

**Особенности:**
- Если значение поля `None` (отсутствует), оно не отображается в заголовке, даже если соответствующий чекбокс включён.
- Quality/LCRR/intensity_coverage не рассчитываются для matched_sequence при неполном совпадении в белке (`identity < 1.0`) — для таких строк эти поля всегда `None` и не выводятся.
- Gene подтягивается из таблицы `protein` через join по `protein_id` (доступен только для matched-строк; для исходной identification — `None`).
- Определён единый источник истины `HEADER_FIELD_OPTIONS` в `plot_mixin.py` — GUI-код строит чекбоксы динамически, что исключает рассинхронизацию списка полей между core и gui (поля/лейблы/дефолты заданы в одном месте).

## Bug Fixes & Improvements

### Отчёты Volcano / PCA / Median — обработка outlier, пустых и недостающих данных

Масштабная переработка обработки данных в трёх отчётах, опирающихся на `get_protein_quantification_data`. Ранее образцы с флагом `outlier` молча включались в анализ, а пустые/`NULL` значения абсолютных концентраций (`abs_value_gl`, `abs_value_mol`) приводили к падениям или к `inf`/`NaN` в результатах.

**Учёт флага `outlier`:**
- В `get_protein_quantification_data` добавлен параметр `exclude_outliers: bool = True` (SQL-условие `AND (s.outlier = 0 OR s.outlier IS NULL)`). Одно изменение в data-слое закрывает Volcano, PCA и Median.
- В GUI-формы отчётов (`VolcanoReportForm`, `PCAReportForm`, `MedianReportForm`) добавлен чекбокс **«Include outlier samples»** (по умолчанию выкл.) — пробрасывается как `include_outliers` → `exclude_outliers = not include_outliers`.
- Новый хелпер `get_subset_sample_counts(exclude_outliers, subsets)` в `sample_mixin` — возвращает **истинное** число образцов по имени подгруппы (с учётом outlier). Заменяет ошибочный вывод размера подгруппы из самих данных квантификации (который занижался при отсутствии белков у образца и неверно включал аутлайеры в знаменатель).

**Volcano Report:**
- Значения контрольной и экспериментальных групп теперь очищаются через `dropna()` перед передачей в статистические тесты — ранее `NULL`-абсолюты (`g/l`, `mol/l`) попадали в `mannwhitneyu`/`ttest_ind` как `NaN` и вызывали падение/`NaN`-результат.
- `get_pval` обёрнут в `try/except` → `None` на degenerate-входе (n=1 для t-test → `nan`, одинаковые группы, неизвестный критерий).
- Защита деления FC: сравнение пропускается, если `ctrl_median == 0`/`NaN` или `exptl_median` не-finite — больше нет `inf`/`NaN` в `fc_log2`.
- **FDR-коррекция (`fdc`) больше не игнорируется:** добавлен `correct_pvals(p_values, method)`. `BH`/`BY` делегируются в `scipy.stats.false_discovery_control` (`method='bh'/'by'`); **`Bonferroni` реализован вручную** (`min(p*n, 1.0)`) — scipy эту опцию не поддерживает.
- `subset_lenghts` теперь берётся из БД через `get_subset_sample_counts` — корректный знаменатель для `is_sufficient` и `% samples`.
- Перед отбором POI добавлен `dropna(subset=['max_fc','min_pval'])` — ранее `None` в object-dtype колонках мог вызывать `TypeError` в `calculated.query(...)`. Хелперы `get_min_pval`/`get_max_fc_log2` переписаны с фильтром не-finite значений.
- `draw_plot`: убран отладочный `print(df)`; вместо общего `Exception("Not enough data…")` — понятный `ValueError` при пустом `figure_df`.
- Убран неиспользуемый импорт `logger`.

**PCA Report:**
- `_compute_pca`: перед `fillna` дропаются all-NaN колонки (белки без значений ни в одном образце) и zero-variance колонки — ранее `fillna(median)` оставлял all-NaN колонку нетронутой, `StandardScaler`+`PCA` падали с «Input contains NaN».
- Явные `ValueError` при отсутствии пригодных фичей и при `n_comp < 2` (нельзя построить 2D PCA) — вместо `KeyError` на `PC2`/`IndexError` на `explained[1]` в `_build_pca_figure`.
- В `_generate_impl` дропаются образцы (строки) без квантификации по всем белкам; проброс `exclude_outliers`.
- `roc_curve` обёрнут в `try/except` — degenerate `y_true`/non-finite `pc1` пропускают подгруппу вместо падения.

**Median Report:**
- Проброс `exclude_outliers`; `sample_counts` теперь из `get_subset_sample_counts` (с фильтром outlier) — знаменатели согласованы с отфильтрованными данными.
- Нормализация `subsets`: `None`/пустой список → все подгруппы, присутствующие в данных (раньше `for subset in None` падало, а пустой список давал `KeyError` на `sample_counts[subset]`).
- Guard делителей: `% of total samples` / `% of subset_samples` защищены от деления на 0; **CV** теперь `None` вместо `inf`/`NaN` при `mean == 0`/`NaN`.

**Проверка:** синтаксис (`py_compile`), импорты модулей, а также runtime-тесты хелперов (`correct_pvals` для BH/BY/Bonferroni/empty/None; edge-cases `_compute_pca` — all-NaN/constant/1-компонента поднимают `ValueError`, валидные случаи дают 2D-скоры; `get_pval` на degenerate-входах возвращает `None`/`nan`).

## Notes

- `PROJECT_VERSION` / `APP_VERSION` **не повышаются** — управляется разработчиком при сборке.
- Миграция БД не требуется — все используемые поля (`quality`, `lcrr`, `intensity_coverage`, `gene`, `matched_coverage_percent`, `outlier`) уже существуют в схеме.
- В `pyproject.toml` не настроены `ruff`/`mypy` — проверка выполнена через `py_compile`, импорт модулей и runtime-тесты хелперов.
