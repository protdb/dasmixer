## New Features

### Копирование графика в clipboard (BasePlotView → Copy)

Во все представления графиков на базе `BasePlotView` (Peptide Ion Plot, Protein Concentration Plot) добавлена кнопка **Copy** — первая в ряду кнопок под превью (`Copy | Save to Project | Export... | Interactive`). По клику PNG-изображение текущего графика копируется в системный буфер обмена, после чего показывается зелёный snack bar **"Plot copied!"**. Ошибки логируются через `logger.exception()` и сопровождаются красным snack bar'ом.

**Нюанс реализации (важно):** в Flet 0.81.0 метод `ft.Clipboard().set_image()` на desktop выбрасывает `FletUnsupportedPlatformException` (поддерживается только Android/iOS/Web). DASMixer — desktop-приложение, поэтому реализован модуль `dasmixer/gui/components/clipboard.py` со стратегией **flet-first → native fallback**:

- Сначала пробуется `ft.Clipboard().set_image()` (на случай запуска в web-режиме или будущих версий flet с поддержкой desktop).
- При недоступности — платформенный fallback:
  - **Windows:** `pythonnet` (уже в зависимостях) — `System.Windows.Forms.Clipboard.SetDataObject` с форматами `PNG` (прозрачность) и `Bitmap`, в STA-потоке `.NET`;
  - **Linux:** `wl-copy --type image/png` (Wayland) или `xclip -selection clipboard -t image/png` (X11);
  - **macOS:** `osascript` + временный PNG-файл (`«class PNGf»`).
- Все блокирующие вызовы выполняются в executor'е (`loop.run_in_executor`), чтобы не замораживать UI.
- Для копирования переиспользуется кэш превью `_last_img_bytes` (то, что пользователь видит на экране), при его отсутствии выполняется защитный ре-рендер через `render_png_async`.

Новых Python-зависимостей не требуется.

### ColorPicker на базе `flet-color-pickers` (0.81.0)

Поля ввода цвета в DASMixer переведены на визуальный контрол из пакета `flet-color-pickers` (уже добавлен в зависимости). Создан переиспользуемый GUI-компонент `dasmixer/gui/components/color_picker.py` — `ColorPickerField` с превью, слайдерами/палитрой и текстовым полем hex.

**Форматы:**
- Внешний API и хранение — `#RRGGBB` (без изменений схемы БД/конфига);
- Внутри (для `flet-color-pickers`) — `#AARRGGBB`, alpha всегда `FF`.

**Режимы компонента:**
- `compact=False` (full) — превью + `SlidePicker` + text field в одну строку. Используется в диалогах создания/редактирования группы (`GroupDialog`) и инструмента (`ToolDialog`). Ширина диалогов увеличена с 400 до 460 px для комфортного размещения слайдеров.
- `compact=True` — компактная строка (кликабельное превью + text field + кнопка удаления); пикер (`ColorPicker` с палитрой) открывается в `AlertDialog` по клику на превью. Используется на странице **Settings → Default Color Palette**.

**Синхронизация:** превью ↔ слайдеры/палитра ↔ hex-поле обновляются двунаправленно; live-валидация ввода (`#RRGGBB` без `#`, до 6 символов); ошибка подсвечивается красным при потере фокуса; на `on_blur` невалидное значение не сохраняется (в диалогах — `set_error("Invalid color")` + прерывание сохранения; в настройках — подсветка поля и блокировка Save).

**Затронутые места выбора цвета:**
- `dialogs/group_dialog.py`, `dialogs/tool_dialog.py` — заменены `TextField` + статичное превью на `ColorPickerField` (full-режим);
- `views/settings_view.py` — строки палитры `default_colors` переведены на `ColorPickerField` (compact-режим), удалены локальные regex-хелперы и обработчики live-превью (логика ушла в компонент).

## Notes

- `APP_VERSION` / `PROJECT_VERSION` **не повышаются** — управляется разработчиком при сборке.
- Миграция БД не требуется — `display_color` продолжает храниться в формате `#RRGGBB`.
- В `pyproject.toml` не настроены `ruff`/`mypy` — проверка выполнена через `py_compile`, импорт модулей, `ruff check` по новым файлам и runtime-проверку clipboard-helper (Windows: pythonnet-путь) и `ColorPickerField` (конструирование, `value`/`is_valid`/`set_error`, оба режима).
- Ручной smoke-тест (разработчик): сгенерировать график → **Copy** → вставить в Word/Paint; создать/отредактировать группу и инструмент → проверить слайдеры; Settings → Default Color Palette → клик по превью открывает палитру, добавление/удаление/сохранение работает.
