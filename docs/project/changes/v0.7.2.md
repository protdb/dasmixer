# v0.7.2

**Date:** 2026-09-03

---

## New Features

- **Identification quality scores** — Ion Coverage now stores quality metrics for every peptide–spectrum match:
  - **Quality** (0–1) — overall spectrum/match quality (Bern et al., 2004);
  - **LCRR** (Longest Consecutive Run Ratio) — how continuously the peptide sequence is confirmed by fragment ions;
  - **Unconfirmed PTMs** — number of modifications not supported by any matched fragment ion.
- **Preferred identification thresholds** — new tool settings **Min Quality**, **Min LCRR** and **Max Unconfirmed PTMs** refine automatic preferred selection (ignored when "Trust all identifications" is enabled).
- **Peptide Identifications table** — new columns (Quality, LCRR, Unconfirmed PTMs, computed Charge/Pepmass with source values) and new filters **Min Quality**, **Has PTM**, **Has AA Substitution**, **Sequence Identified**.
- **Clear Calculations** — one-click reset that restores original sequences and clears all calculated fields across the project.
- **Customizable subplot headers** in the Peptide Ion Plot — choose which fields (tool, sequence, identity, score, PPM, protein ID, etc.) appear above each spectrum.
- **PeptideShaker import** — new parser for PeptideShaker XLS identification exports, automatically matched to imported spectra.
- **Peptide Ion Plot improvements** — better automatic plot sizing when several sequences are displayed; correct spectrum rendering without a sequence.
- **Plot controls & interaction**:
  - **Copy** button on plot views copies the current plot image to the clipboard;
  - interactive plots match the GUI size and open at the largest available window size;
  - fragment sequence annotations appear on hover in interactive mode.
- **Visual color pickers** — subset/tool dialogs and the Default Color Palette in Settings now use a dedicated color picker instead of manual hex entry.
- **Plot appearance settings** — configurable plot **aspect ratio** and **view mode** (Window or default browser) for plots and reports.
- **Project name shown in the window title** and app bar while a project is open.
- **Open Recent menu item** — quick access to recent projects from the File menu.

## Bug Fixes

- **ProForma sequences** with two or more N-terminal modifications now import correctly (pyteomics update).
- **Spectrum ID filter** in the peptide table works again.
- **Matched sequences** in the Peptide Ion Plot are shown correctly for partial protein matches, including modifications.
- **PLGS import** no longer drops modified (PTM) sequences.
- **Volcano, PCA and Median reports** correctly handle outlier samples and missing/empty data — outlier samples are excluded by default (with an option to include them), sample counts and denominators are accurate, and FDR correction (including Bonferroni) is applied properly.
- **Overlapping dialogs** no longer appear when opening older projects that require a database upgrade.
- **App settings** no longer fail to load when the config file contains unknown keys (for example, after switching between versions).
- **Browser-mode plots on Linux/macOS** no longer fail to open from the system temp folder; temporary HTML files are now cleaned up automatically on application start.
