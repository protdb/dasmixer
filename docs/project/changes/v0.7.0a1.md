# v0.7.0a1

**Date:** 2026-07-05

---

## New Features

### Import Additional Sample Data
- **New button "Import additional data"** in ManageSamplesView (`UpdateRow`) — opens file picker for `.xlsx`/`.csv`.
- **Preview dialog** with column selector and color-coded intersection table:
  - 🟢 Green: sample present in both file and project
  - 🟡 Yellow: sample only in project (no data in file)
  - 🔴 Red: sample only in file (not in project)
- **Selective import** — only matching samples are imported; samples without data in file are skipped; rows without matching project samples are ignored.
- **Smart merge** — new additionals keys are merged with existing `sample.additions` dict (values overwritten), per-sample (not batch).
- **Additionals indicator** in sample panel header — `☐` (no data) / `☑` (has data); samples missing additionals when others have them are highlighted in amber.
- New core method: `Project.get_additionals_keys()` — collects all unique JSON keys from `sample.additions` across all samples.

### LFQ: Absolute Concentrations
- **Checkbox "Abs. concentrations"** in the LFQ section on the Proteins tab — enables absolute concentration calculation.
- **"Set references" dialog** — configures:
  - Dropdown for **Total protein field** (key from sample additionals)
  - Dropdown for **Reference protein field** (key from sample additionals)
  - Text field for **Reference protein ID** (default: `P02768`)
  - Checkbox **Use default concentrations** + two numeric fields (default reference value 40.0 g/l, default total protein 75.0 g/l)
  - All settings saved to `project_settings` under `lfq_abs_*` keys
- **Intelligent source selection** per LFQ method:
  - `emPAI` and `NSAF` — preferred: total protein, fallback: reference protein
  - `iBAQ` and `Top3` — preferred: reference protein, fallback: total protein
- **Per-sample concentration resolution** — reads `total_protein_gl`/`reference_protein_gl` from `sample.additions` using configured field names; falls back to defaults when configured.
- Results stored in both `abs_value_mol` (mol/l) and `abs_value_gl` (g/l) columns.

### LFQ Save Logic Refined
- **Algorithm-specific clearing** — `clear_protein_quantifications_for_sample_and_algorithm(sample_id, algorithm)` deletes only records for a specific algorithm, preserving previously calculated values for other algorithms.
- Database migration (0.7.0): `abs_value` renamed to `abs_value_mol`, new column `abs_value_gl` added to `protein_quantification_result`.

### Protein Plot: Value Type & Multiplier
- **New radio group** on concentration plot: `rel` / `g/l` / `mol/l` — selects which data column to display.
- **New multiplier dropdown** (active only for absolute values): ×1, ×10³ (milli), ×10⁶ (micro), ×10⁹ (nano), ×10¹² (femto).
- **Dynamic Y-axis label** — e.g., `"iBAQ, μg/l"` or `"Top3, nmol/l"`, reflecting multiplier prefix and unit.

### Report Forms: LFQSelector Component
- **New `LFQSelector` widget** in `report_form.py` — composite control with algorithm dropdown (emPAI/iBAQ/NSAF/Top3) and value type radio (rel/g/l/mol/l).
- Returns `tuple[str, str]` — `(algorithm_name, db_column_name)`.
- Replaces `EnumSelector` for `lfq_type` in PCA and Volcano report forms.
- PCA and Volcano reports updated to extract the algorithm name from the new tuple parameter.

### Top3 Returns `None` for Fewer Than 3 Peptides
- `calculate_top3_value()` in `sempai/algorithms.py` now returns `None` (not `0.0`) when fewer than 3 peptide intensities are available.
- `Protein.top3` property in `sempai/protein.py` returns `Optional[float]` — `None` when < 3 peptides.
