# v0.7.4a4

**Date:** 2026-10-10

---

## Summary

Реализация импорта датасетов из репозитория PRIDE в открытый проект DASMixer (core + GUI + CLI). Функционал строится поверх существующих классов `PrideDataset`/`PrideFile` (`dataset.py`) и повторяет архитектурный паттерн импорта MaxQuant. Идентификации импортируются в двух режимах — `single` (один mzTab на несколько спектральных файлов, резолвинг `ms_run` → `spectra_file_id` по location) и `per_sample` (один ident-файл на каждый спектральный файл). Без изменения схемы БД.

## Core Changes

### Зависимость `pridepy` — `pyproject.toml`

- Добавлен опциональный extra `pride = ["pridepy ==0.0.16"]` в `[project.optional-dependencies]`.
- Extra `all` расширен до `dasmixer-core[plotly,proteins,pride]`.

### `progress.py` (**New**)

Новый модуль `dasmixer-core/src/dasmixer/api/inputs/complex/pride/progress.py`:

- `PrideImportProgress` — dataclass с полями `stage`, `message`, `current = 0`, `total = 0`. Общий тип сообщения прогресса для GUI и CLI.

### `importer.py` (**New**)

Новый модуль `dasmixer-core/src/dasmixer/api/inputs/complex/pride/importer.py`:

- `PrideImportOptions` — dataclass параметров импорта: `dataset_id`, `subset_id`, `spectra_parser` (`"MGF"`), `ident_parser` (`"mzTab"`/`"CasaNovo"`), `ident_mode` (`"single"`/`"per_sample"`), `tool_name`, `selected_spectra_files`, `ident_file_mapping` (`{spectra_name: ident_name}` для `per_sample`), `single_ident_file`, `import_fasta`, `collect_proteins`, `delete_temp_files`.
- `ProgressCallback = Callable[[PrideImportProgress], Awaitable[None]]`.
- `run_pride_import(project, dataset, options, progress_callback=None) -> dict` — полный цикл импорта в 5 шагов:
  1. **Скачивание** выбранных файлов через `asyncio.to_thread(file.download_file)` с `asyncio.sleep(0.1)` между файлами (стадия `"downloading"`).
  2. **Спектры** — для каждого выбранного `.mgf` создаётся/находится Sample (имя = stem файла), `add_spectra_file` + батч-импорт через реестровый парсер (стадия `"spectra"`).
  3. **Идентификации** — get-or-create Tool (`"Library"` для `mzTab`, `"De Novo"` для `CasaNovo`); режим `single` зеркалит `import_identification_files_multifile` (один `identification_file` на каждый разрешённый `ms_run`, `selection_field="mz_run"`); режим `per_sample` зеркалит `import_identification_files` (один ident-файл на спектральный файл) (стадия `"identifications"`).
  4. **FASTA** — опциональный импорт белков через `FastaParser` + `add_proteins_batch` (стадия `"fasta"`).
  5. **Сохранение** (`project.save(checkpoint=True)`) + опциональная очистка temp-файлов (`shutil.rmtree(get_pxd_temp_dir()/dataset_id)`) (стадия `"done"`).
- Возвращает summary: `samples_processed`, `spectra_imported`, `identifications_imported`, `fasta_files_imported`.
- `check_pride_available() -> bool` — быстрая проверка: импорт `pridepy` + сетевой probe к PRIDE WS (используется GUI для показа ошибки).

### `__init__.py` — публичное API

- Дополнен экспорт пакета `pride`: `PrideDataset`, `PrideFile`, `PrideDatasetNotFoundException` (из `dataset.py`), `PrideImportOptions`, `ProgressCallback`, `check_pride_available`, `run_pride_import` (из `importer.py`), `PrideImportProgress` (из `progress.py`).

## GUI Changes

### `pride_import_section.py` (**New**)

`PrideImportSection(BaseSection)` — секция «Import From PRIDE» с кнопкой `Import PRIDE dataset...`, вызывающей `parent_tab.show_import_pride()`.

### `dialogs/import_pride_dialog.py` (**New**)

`ImportPrideDialog` — трёхэкранный wizard (по образцу `ImportMaxQuantDialog`):

- **Экран 1** — ввод PXD identifier + кнопка `Check` (в одной строке с полем). Обработка ошибок: `DasmixerNetworkException` → «No network connection…», `PrideDatasetNotFoundException` → «Dataset \`{id}\` not found…», отсутствие подходящих файлов (нет `.mgf` или `.mztab`) → экран 2 с предупреждением о поддерживаемых форматах.
- **Экран 2** — конфигурация: строка с PXD identifier + `Check` (переключение датасета), название датасета (увеличенный шрифт) и описание на всю ширину; `Import Settings` в одну строку (Subset / Spectra parser / Tool name); Subset с первой группой по умолчанию; список `.mgf` с чекбоксами + Select All / Deselect All; `RadioGroup` single/per_sample; ident-парсер (`mzTab` всегда, `CasaNovo` только в `per_sample`); выбор ident-файлов (single — один Dropdown, per_sample — маппинг с автопривязкой по совпадающему stem имени файла без расширения); галочки `Import protein data`, `Import protein mapping`, `Delete downloaded files` (первые две по умолчанию включены, последняя — выключена).
- **Экран 3** — прогресс (`ProgressBar` + текст стадии).
- Lazy-загрузка модуля `pride` через `_load_pride_module()` — при отсутствии `pridepy` показывается понятное сообщение об установке `dasmixer-core[pride]` без обращения к сети.

### `samples_tab.py`

- Импорт и регистрация `sections['import_pride'] = PrideImportSection(...)`.
- Третий контейнер `import_pride` в `ft.Row` импортов (рядом с `import` и `import_maxquant`).
- Методы `show_import_pride()` / `_show_import_pride_dialog()` (по образцу `show_import_maxquant` / `_show_import_maxquant_dialog`).

## CLI Changes

### `import_data.py` — команда `pride`

- Новая команда `dasmixer-cli import pride PROJECT_PATH DATASET_ID` с опциями: `--tool-name`, `--subset-name`, `--spectra-parser`, `--ident-parser`, `--import-fasta/--no-import-fasta`, `--collect-proteins/--no-collect-proteins`, `--delete-temp-files/--keep-temp-files`.
- Режим `single`: все `.mgf` — спектры, первый `.mztab` — идентификации; маппинг по `ms_run` location выполняется внутри `run_pride_import`.
- Обработка `DasmixerNetworkException` / `PrideDatasetNotFoundException` / `ImportError` (pridepy не установлен) с выводом ошибки и `typer.Exit(1)`.
- Проект создаётся при отсутствии; при создании добавляется в `recent_projects`.

## Notes

- `dataset.py` (`PrideDataset`/`PrideFile`) существовал до этой версии и **не изменялся** — в 0.7.4a4 вокруг него добавлены `importer.py`, `progress.py` и публичный `__init__.py`.
- `PrideFile.download_file()` использует `skip_if_downloaded_already=True` — повторный импорт не перекачивает файлы; при `delete_temp_files=True` temp-каталог датасета удаляется после импорта.
- `pridepy` — опциональная зависимость; при отсутствии пакета GUI/CLI показывают подсказку установить `dasmixer-core[pride]`, а `check_pride_available()` возвращает `False`.
- `APP_VERSION` / `PROJECT_VERSION` **не повышались** (обновляются скриптом сборки; по правилам AGENTS.md агентом не меняются).
- Схема БД без изменений → `PROJECT_VERSION` остаётся без изменений, миграций нет, `import_project_mixin.py` не затрагивался.
- Интеграционные тесты не писались (по правилам AGENTS.md); проверка — `py_compile`/`ast.parse` новых и изменённых файлов.
- Changelog создан по явному запросу Developer.
