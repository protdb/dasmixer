# v0.7.0

**Date:** 2026-07-17

---

## New Features

### Import Additional Sample Data
- New "Import additional data" button in ManageSamplesView — opens `.xlsx`/`.csv` files with a preview dialog showing color-coded intersection (green = in both, yellow = project only, red = file only).
- Selective import: only matching samples are imported; additionals keys are merged per-sample.
- Additionals indicator (`☐`/`☑`) in sample panel header, with amber highlight for missing data.

### LFQ: Absolute Concentrations
- Absolute concentration calculation with configurable reference protein and total protein fields from sample additionals.
- Intelligent source selection per LFQ method: emPAI/NSAF prefer total protein; iBAQ/Top3 prefer reference protein.
- Results stored in both `abs_value_mol` (mol/l) and `abs_value_gl` (g/l) columns.
- Per-sample concentration resolution with fallback to defaults.
- Algorithm-specific clearing — preserves previously calculated values for other algorithms.

### Protein Plot: Value Type & Multiplier
- Radio group to select value column: rel / g/l / mol/l.
- Multiplier dropdown for absolute values (×1, ×10³, ×10⁶, ×10⁹, ×10¹²).
- Dynamic Y-axis labels (e.g., `"iBAQ, μg/l"`).

### Tool Settings Form (Peptides Tab)
- Form reorganized into 4 visual blocks with locking logic.
- New **Trust PPM** flag — skips PPM recalculation when trust is enabled.
- New **Recalculate PTMs** flag — when enabled, locks the PTM block; passes `unallocated_only` downstream.

### Report Forms: LFQSelector
- New composite `LFQSelector` widget (algorithm dropdown + value type radio).
- PCA and Volcano reports use it instead of plain EnumSelector.

### Top3 Returns `None` for < 3 Peptides
- `calculate_top3_value()` now returns `None` (not `0.0`) when fewer than 3 peptide intensities are available.

### PPM/PTM Pipeline
- `process_single_ident()` and `process_identificatons_batch()` accept `trust_ppm` and `unallocated_only` parameters.
- `SeqFixer.__init__()` accepts `unallocated_only` — skips PTM candidate search when set.
- `IdentificationWithSpectrum` dataclass now carries `ppm` field.

### Core: Split-Query Aggregation (Fast Sample Stats)
- `get_all_samples_stats()` rewritten from a single CTE query (~30s) to 6 parallel split-queries + Python merge (~0.6s, ~50× faster).
- Sample status cache table (`sample_status_cache`) is no longer read or written; statistics are computed fresh on each view open.

## GUI Improvements

### ManageSamplesView Overhaul
- **Pagination** — configurable page size (10/20/50/100/All) with prev/next, filtering over in-memory data (no SQL).
- **Filters** — search by name, status (OK/WARNING/ERROR), subset, outlier; all filters persisted in `project_settings`.
- **Lazy accordion expansion** — body built only on first expand, cached in memory, removed from Flet tree on collapse.
- **Persistent thresholds** — `min_proteins`/`min_idents` saved to `project_settings`, no longer reset on reopen.
- **Loader** — `ProgressRing` shown during the ~0.6s stats query.
- **Dead code removed** — `samples_section.py` deleted.

### Tool Settings Form Layout
- 4-block layout with visual separation, label renamed `"I/L Combinatorics"`.
- Block locking: `ignore_criteria` locks Block 2, `recalculate_ptms` locks Block 3, `use_protein_from_file` locks Block 4.
- Settings include `ignore_criteria`, `trust_ppm`, `recalculate_ptms`.

## Bug Fixes

### Unlocalized PTM (ProForma `?`) Crash & Infinite Loop
- `_expand_unlocalized()` in `seqfixer.py` expands unlocalized modifications into all valid positional variants (guarded by `_MAX_UNLOCALIZED_COMBOS=256`).
- `process_single_ident()` picks the best variant by `intensity_percent`.
- Exception handler writes `intensity_coverage=0` (not `NULL`) to prevent infinite re-processing.
- Unconditional stderr fallback print added for visibility.

### Schema — `protein_quantification_result` Column Mismatch
- `schema.py` CREATE TABLE updated: `abs_value` → `abs_value_mol REAL` + `abs_value_gl REAL` (matches migration), preventing failures on fresh projects.

### MGF Export Metadata Loss
- `all_params` passthrough: preserves original fields (INSTRUMENT, RTINSECONDS, etc.).
- `PEPMASS` now includes precursor intensity.
- Peak charge third column restored (from `charge_array_common_value` or per-peak BLOB).
- `SCANS` fallback to `spec_row.scans`.
- Spectra sorted by `seq_no` (original file order), not by DB `id`.
- File header comment: `# Exported from DASMixer`.
- Peak charges written as integers (`1`), not floats (`1.0`).

### `matching.py` — KeyError: nan on Preferred Selection
- Added `dropna()` before `idxmin()`/`idxmax()` — spectra with all-NaN candidates are now skipped.

### "Trust All Identifications" Not Saving to DB
- `ignore_criteria` key added to `save_tool_settings()` dictionary.

### "Trust All Identifications" Logic
- `calculate_preferred_identifications_for_file()` rewritten: instruments with `ignore_criteria=True` form a **trusted pool** (no quality filters), others form a **normal pool**; trusted pool takes priority per spectrum.

### Misc
- `ft.Dropdown(on_change=...)` → `on_text_change=...` in pagination (Flet 0.80.5 API).
- Subset dropdown in filter row populated from real subsets.
- `_load_data()` wrapped in try/except with logging.
- Fixed duplicate `_load_data()` calls and lost method references in ManageSamplesView.
