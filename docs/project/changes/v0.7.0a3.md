## Bug Fixes

### "Trust all identifications" — `ignore_criteria` не сохранялся в БД

**Проблема:** Флаг `ignore_criteria` (Trust all identifications) в настройках инструмента на вкладке Peptides никогда не попадал в базу данных. В методе `save_tool_settings()` ключ `ignore_criteria` отсутствовал в словаре настроек, поэтому при повторной загрузке проекта значение всегда сбрасывалось в `False`.

**Fix — `tool_settings_section.py`:** Добавлен `'ignore_criteria': bool(controls['ignore_criteria'].value)` в словарь `tool.settings` в методе `save_tool_settings()`.

### "Trust all identifications" — логика выбора preferred идентификаций

**Проблема:** Функция `calculate_preferred_identifications_for_file()` полностью игнорировала `ignore_criteria` — всегда применяла все фильтры качества (PPM, score, coverage, длина пептида, кол-во пиков, ионов) через `get_idents_for_preferred()`. Кроме того, критерий выбора (`ppm` / `intensity`) не применялся — всегда выбирался лучший по `min_ppm`.

**Fix — `matching.py`:** Полностью переписана `calculate_preferred_identifications_for_file()`:
- Инструменты с `ignore_criteria=True` формируют **trusted pool** — все идентификации без фильтров качества
- Инструменты с `ignore_criteria=False` формируют **normal pool** — с фильтрацией по стандартным критериям
- **Приоритет:** для каждого спектра сначала выбирается лучшая идентификация из trusted pool; если их нет — из normal pool
- Критерий выбора (`ppm` → min |PPM|, `intensity` → max intensity_coverage) корректно применяется в обоих пулах

**Fix — `identification_mixin.py`:** Добавлен новый метод `get_all_idents_for_preferred()` — возвращает все идентификации для файла+инструмента без WHERE-фильтров по качеству. Колонки совместимы с `get_idents_for_preferred()`.
