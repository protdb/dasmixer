# v0.5.0 — Разделение на подпакеты

**Дата:** 2026-06-11

---

## Изменения

### Архитектура

- **Монолитный пакет → 4 подпакета** в монорепозитории:
  - `dasmixer-core` — API для работы с проектами, вычисления, импорт данных (внутренний модуль `dasmixer.api`)
  - `dasmixer-gui` — Flet-графический интерфейс (модуль `dasmixer.gui`)
  - `dasmixer-cli` — CLI-инструменты для управления проектами (модуль `dasmixer.cli`)
  - `dasmixer` — зонтичный метапакет (только зависимости)
- **Namespace Packages (PEP 420)**: все подпакеты вносят вклад в общее пространство имён `dasmixer`. Директории `src/dasmixer/` не содержат `__init__.py`.
- Переход на `src`-layout: исходный код в `*/src/dasmixer/`
- Все пакеты имеют версию `0.5.0` и строгие зависимости друг от друга (`==0.5.0`)

### Зависимости

- **dasmixer-core**:
  - Обязательные: pandas, numpy, aiosqlite, pydantic, typer, pyteomics, peptacular и др.
  - Опционально `[plotly]`: plotly + kaleido
  - Опционально `[proteins]`: npysearch
  - Полная: `dasmixer-core[all]`
- **dasmixer-gui**: dasmixer-core[all], flet, pywebview, pythonnet
- **dasmixer-cli**: dasmixer-core (без extras)

### Отделение API-слоя от GUI

- **Убран мёртвый импорт** `from flet.controls.core import row` из `api/project/core/lifecycle.py`
- **Mock-объект Icons**: `api/reporting/_icons.py` — при отсутствии flet возвращает имя атрибута строкой через `__getattr__`
- **BaseReport**: иконка теперь через `Icons.REPORT` (mock), не зависит от flet
- **ReportForm разделён на два слоя**:
  - `api/reporting/report_form.py` — абстрактный базовый класс без flet (core)
  - `gui/components/report_form.py` — наследник с flet-specific `build()` и `get_container()` (GUI)
- **Формы отчётов убраны из API**, перенесены в `gui/reports/forms.py` с monkey-patch
- **viewer.py перемещён** из `api/reporting/` в `gui/reporting/` (pywebview — GUI-зависимость)

### Точки входа

| Команда | Пакет | Entry point |
|---|---|---|
| `dasmixer` | `dasmixer-gui` | `dasmixer.gui.main:app` |
| `dasmixer-cli` | `dasmixer-cli` | `dasmixer.cli.main:app` |
| `python -m dasmixer` | `dasmixer-gui` | `__main__.py` |

- `gui/main.py` — запуск GUI + загрузка плагинов + инициализация Chrome (kaleido)
- `cli/main.py` — 3 sub-команды: `create`, `subset`, `import`
- Все CLI-команды теперь принимают `project_path` как прямой аргумент (не через `ctx.parent`)
- Старые `dasmixer/main.py`, `dasmixer/__init__.py`, `dasmixer/__main__.py` удалены

### Tooling

- `build_all.sh` — скрипт сборки и публикации (build → TestPyPI → PyPI с подтверждениями)
- `Makefile` — `make dev-install` / `make dev-uninstall`
- `pyproject.toml` (корень) — Poetry workspace для разработки
- `dasmixer.spec` — обновлён путь к entry point

### Прочее

- Версия `versions.py` поднята с `0.4.0` до `0.5.0`
- `dasmixer/utils/` и `dasmixer/versions.py` перемещены в `dasmixer-core`
- Все файлы перемещены через `git mv` (история сохранена)
