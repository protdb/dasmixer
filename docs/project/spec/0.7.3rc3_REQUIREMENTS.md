# 0.7.3rc3: Добавить поля FDR и e-value при импорте

Требуется добавить поля:
- fdr
- e_value
- q_value

в табилцу Identifications. Все три: nullable real. Версию проекта с этим поднимаем до 0.7.3.

Добавляем их при работе с идентификациями:
- Импорт из файла;
- переименование в классе ColumnRenames (`dasmixer-core/src/dasmixer/api/inputs/peptides/table_importer.py`), все параметры опциональны, их может не быть во входных данных, столбцы могут отсутствовать
- get_joined_peptide_data
- Отображение в таблице пептидов (`dasmixer-gui/src/dasmixer/gui/views/tabs/peptides/peptide_ion_table_view.py`, читабельные имена: FDR, e-value, q-value, по умолчанию не отображаются, но могут быть включены)

Отдельно для FDR:
- Возможность фильтра FDR (не более заданного) в настройках инструмента на вкладке пептидов. Здесь важно: даже если значение задано, идентификации с FDR = NULL должны проходить фильтр. Обоснование: не расчётная величина. В отличие от расчётных, может быть пустой и это не означает ошибку.
- Возможность фильтра по FDR (не более заданного) в таблице пептидов на той же вкладке

По логике добавления полей (на примере полей, заполняемых при вычислении): docs/project/spec/0.7.2a1_SPEC.md

Здесь примерно те же этапы для FDR и остальных полей, но важная поправка: FDR и пр. не расчётные величины, а импортируемые и только импортируемые.
