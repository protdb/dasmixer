## Копирование графиков

В BasePlotView необходимо добавить кнопку Copy (первой в ряду с другими кнопками под графиком), по клику на которую изображение будет копироваться в clipboard.

Для этого используем `await ft.Clipboard().set_image(img_bytes)`, функционал flet 0.81.0

После выполнения, показываем зелёный snack bar "Plot copied!"

Ошибки при копировании логируем в logger.exception()
