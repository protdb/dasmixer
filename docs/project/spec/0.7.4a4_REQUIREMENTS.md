# 0.7.4a4 Импорт проектов Pride

На сонове дополнений предыдущего этапа реализуем импорт проектов из PRIDE в минимальном виде

## GUI:

Добавляем новый блок на страницу Samples в общем ряду с import spectra и import maxquant project: Import PRIDE dataset

По нажатию открывается окно импорта датасета, в котором есть поле ввода: PXD identifier и кнопка "Try".

По нажатию возможны четыре варианта поведения:
- Отсутствует сетевое подключение: отображается соответствующая ошибка, поле ввода доступно для редактирования
- Некорректный ID датасета (сетевое подключение есть, но датасет не найден): отображается соответствующая ошибка, поле ввода доступно для редактирования
- Датасет найден, но в нём отсутствуют файлы подходящих форматов: всё то же самое, ошибка содержит списки поддерживаемых форматов файла. название датасета и описание выводятся пользователю
- Всё необходимое на месте: выводится полная форма.

На форме второго этапа, после ввода названия, идут следующие элементы:
- Поле ввода и кнопка Check: позволяют сразу переключиться на следующий датасет
- Заголовок: отображается если доступен
- Описание: текстовый блок фиксированной высоты с прокруткой
- Текст ошибки: только если возникла ошибка

Все блоки ниже отображаются только если всё хорошо
- Subset: выбор из выпадающего списка существующих групп сравнения
- Выпадающий список парсеров для импорта файлов: доступны все системные импортеры файлов спектров
- Список файлов спектров с кнопками select all/deselect all - как при импорте по pattern matching
- Radio button "Identifications import type": Single file/Per sample. Выбор по умолчанию зависит от количества файлов идентификаций в проекте, если подходящий файл один - используем его
- Выпадающий список Identifications parser: должны быть доступны только MzTab и CasaNovo. Второй доступен только если выбран Per sample
- Поле ввода Tool name (название инструмента)
  - Если выбран Single file: один выпадающий список с файлами допустимых форматов
  - Если выбраны multiple file: мэппинг, аналогичный импорту из папки, в ряду с прокруткой.
- Чекбокс "Import protein data": отображается только если в проекте есть FASTA-файлы
- Чекбокс "Import protein mapping": аналогично чекбоксу "Import protein IDs from file", активно если выбран парсер с поддержкой импорта белков (в нашем вырожденном случае - не CasaNovo) 
- Кнопка Import

Следующим этапом отображается диалог прогресса, в нём отображаются последовательно шаги:
- Скачивание данных
- Импорт спектров
- Импорт идентификаций
- Импорт FASTA

## Тенические детали реализации

Для поддержки функционала добавляем к dasmixer-core опциональную зависимость pridepy, опции:
- `dasmixer-core[pride]`
- `dasmixer-core[all]`

Логику импорта держим тут: dasmixer-core/src/dasmixer/api/inputs/complex/pride

В целом подход схож с импортом MaxQuant (dasmixer-core/src/dasmixer/api/inputs/complex/MaxQuantProject), только вместо конвертации возникает этап скачивания, а разметка образцов и привязка их к данным всё ещё нужна.

По кнопке Check пытаемся:
- Получить метаданные проекта, вытащить Заголовок и описание, а также список файлов
- Получить список файлов

В списке файлов не ориентируемся на типы файлов, они нас мало интересуют. Нам здесь важны только их имена и расширения этих имён, а также URL для дальнейшео скачивания.

Список допустимых расширений сейчас:
- Для файлов спектров: .mgf
- Для файлов идентификаций: .mztab

Это именно списки. просто из одного пункта. Список - это задел на будущее, в перспективе будут реализованы парсеры MzIdentML/MzML, которые также будут добавлены.

Импорт данных из табличных форматов не предусматривается во избежание абсолютного хаоса в данных, т.к. очень сложно в данном случае работать с расширениями имён файлов и т.д. Поэтому допустим только импорт в стандартизованных форматах. Эти нюанс в дальнейшем необходмо будет отразить в документации.

Сейчас мной реализован базовый класс для получения метаданных и файлов датасета: dasmixer-core/src/dasmixer/api/inputs/complex/pride/dataset.py

Его - изучить, без острой необходимости не исправлять. Там есть:

класс PrideDataset: принимает в констукторе ID от ползователя, поднимает ошибки при недоступности PRIDE по сети и в случае отсутствия датасета. Списки файлов можно получить через соответствующие property

класс PrideFile: файл в списке, его имя и расширение имени, метод download

списки файлов получаем из соответствующих property, выдаём ошибку если нет файлов одного из типов (спектры, идентификации)

На первом этапе скачиваем все файлы из выбранных, добавляем для душевного спокойствия задержку 0.1 секунды между скачиваниями. Файлы автоматически уже скачиваются во временную директорию в зависимости от системы.

При создании GUI опираемся по максимуму на существующие диалоги для вкладки Samples, опираемся на существующие примеры в других диалогах импорта. Учитываем особенности текущей версии flet для выпадающих списков (!!!)
