# 0.8.0 Roadmap document

Это не документ для разработки, это список задач высокого уровня, которые будут раскрываться в отдельных постановках альфа-версий 0.8.0.

## Изменение GUI
- Замена вкладок Peptides/Proteins на Pipeline/Data
  - Функционал для запуска процессов подряд
  - Сохранение результатов вычислений, параметров предыдущих запусков
  - Отчёты о выполнении
- Сохранение пользовательских фильтров в таблицах, персистентное хранение этих фильтров между запусками приложения
- Сброс данных в таблице
- Перенос загрузки FASTA на вкладку Samples
- SQLite console для проекта
- Журнал сообщений snack bar (отдельный view через settings menu, хранятся последние 100 штук в RAM во время сессии)
- Расширение настроек: kaleido chrome path, режим для графиков CDN/included
- Экспорт: переключение вариантов экспорта через ползунок (аналогично таблицам в protein tab)

## Мелкие изменения
- Валидация ProForma при импорте идентификаций
- Bundled Unimod DB
- Расширенные критерии выбора preferred для нескольких инструментов (убрать из GUI, реализовать последовательную логику выбора, Quality->Ic->PPM)
- Hover-popup со справочной информацией для контролов в 

## Технические улучшения, сборка
- Апгрейд Flet, базовые интеграционные тесты, базовые тесты CLI
- Сборка через Flet(?): тестирование, проверка гипотезы
- Расширенный пайплайн сборки: Linux distribution, AppImage, Snap, Deb в едином pipeline через WSL
- Сборка под MacOS
- Runner для удалённой сборки Windows
- dasmixer-cli в pyinstaller как дополнитлеьный исполняемый файл в bundle
- оффлайн-доступ к plotly (вместо CDN) для JS
- использование kaleido+edge (windows) (?) исследование + реализация если ОК
- Full-offline installer: включая Flet и Chrome

## Интеграция сбора ошибок
- Встроить [Hawk](https://hawk-tracker.ru/), явный флаг сбора ошибок в настройках

## Дополнительный импорт и экспорт
- Импорт Mzml, MZIdentMl, MZTab
- Отдельная настраиваемая логика: парсер формата и парсер последовательности
- Экспорт MzML+MZIdentML
- Импорт целикового проекта из PXD по IDа
- Автоматическое скачивание Fasta из UniProt, кэширование в .csv.gz, быстрая загрузка

## Шаблоны проектов
- Функционал создания, добавления, удаления шаблона проекта, выбора шаблона при создании проекта
- Настройка параметров инструментов по умолчанию в шаблоне и project_settings в зависимости от типа инструмента
- предустановленные шаблоны (MaxQuant project, Trusted PLGS project)

## Работа с протеоформами
- Отдельная вкладка Proteoforms
- Список аминокислотных замен и PTM, примерные позиции
- Частота встречаемости относителньо последовательности пептида, формы
- Отдельный процесс proteoform detection, настройки для исключения стандартных модификаций
