# Спецификация 0.7.4a4 — Импорт проектов PRIDE

## 1. Обзор

Реализация импорта датасетов из репозитория PRIDE (https://www.ebi.ac.uk/pride/) в открытый проект DASMixer. Функционал строится поверх существующего `PrideDataset`/`PrideFile` из `dataset.py` и повторяет архитектурный паттерн импорта MaxQuant.

class PrideImportOptions:
    dataset_id: str                        # PXD identifier
    subset_id: int                         # ID существующего subset

#### Шаги импорта

**Шаг 1: Скачивание файлов**
- stage: `"downloading"`
- Составить список файлов для скачивания: выбранные спектральные + нужные идентификационные + FASTA (если `import_fasta=True`)
- Скачивать последовательно через `asyncio.to_thread(pride_file.download_file)`
- После каждого скачивания — `asyncio.sleep(0.1)`
- `PrideFile.download_file()` уже пишет в `get_pxd_temp_dir() / dataset_id` и пропускает если файл уже скачан

**Шаг 2: Импорт спектров**
- stage: `"spectra"`
- Для каждого выбранного спектрального файла:
  - Создать Sample с именем = stem файла (без расширения), `subset_id` из options
  - `add_spectra_file` + парсинг через реестровый парсер (`options.spectra_parser`)
  - Пакетный импорт спектров

**Шаг 3: Импорт идентификаций**
- stage: `"identifications"`
- Получить класс парсера из реестра по `options.ident_parser`
- Режим `single`:
  - Один idфайл для всех спектральных файлов
  - Парсер `MzTabImporter` умеет работать с `can_import_multifile=True`, резолвит ms_run → spectra_file_id через location
  - `collect_proteins=options.collect_proteins`
- Режим `per_sample`:
  - Для каждой пары `{spectra_file_name: ident_file_name}` из `options.ident_file_mapping` — отдельный вызов парсера

**Шаг 4: Импорт FASTA**
- stage: `"fasta"`
- Только если `options.import_fasta=True`
- Для каждого скачанного FASTA-файла из датасета — `FastaParser` + `add_proteins_batch`

**Шаг 5: Сохранение**
- `await project.save()`
- Опциональная очистка temp-файлов если `delete_temp_files=True`

### 4.2 Задача: создать диалог `ImportPrideDialog`

**Файл:** `dasmixer-gui/src/dasmixer/gui/views/tabs/samples/dialogs/import_pride_dialog.py` (НОВЫЙ)

Диалог — двухэкранный wizard (аналог `ImportMaxQuantDialog`).

#### Экран 1: Ввод PXD identifier

Элементы:
- `ft.TextField` — поле «PXD Identifier» (например `PXD000001`)
- `ft.ElevatedButton("Try")` — запускает проверку

По нажатию «Try» — показать `ft.ProgressRing`, затем асинхронно создать `PrideDataset(dataset_id)`.

**Обработка ошибок:**
- `DasmixerNetworkException` → показать текст «No network connection. Check your internet and try again.», поле остаётся редактируемым
- `PrideDatasetNotFoundException` → показать «Dataset `{id}` not found in PRIDE.», поле остаётся редактируемым
- Нет файлов подходящих форматов → показать ошибку с перечислением поддерживаемых форматов: спектры — `.mgf`; идентификации — `.mztab`. Заголовок и описание датасета при этом всё равно вывести пользователю.
- Всё в порядке → перейти к Экрану 2

Проверка «нет файлов»: `len(dataset.spectra_files) == 0 OR len(dataset.ident_files) == 0`.

#### Экран 2: Конфигурация импорта

Вверху постоянные элементы:
- `ft.TextField` с кнопкой «Check» — переключиться на другой датасет (возвращает на Экран 1 с новым ID)
- Заголовок датасета (`dataset.title`) — если доступен
- Описание (`dataset.description`) — `ft.TextField(read_only=True, multiline=True, max_lines=4)` фиксированной высоты со скроллом
- Блок ошибки — только если возникла

Далее (только если нет ошибки):

**Subset** — `ft.Dropdown` из существующих групп проекта (`project.get_subsets()`). Использовать `ft.DropdownOption` (Flet 0.81+ API).

**Spectra parser** — `ft.Dropdown` из всех зарегистрированных парсеров спектров (`registry.get_spectra_parsers().keys()`).

**Список файлов спектров** — `ft.ListView` с `ft.Checkbox` для каждого `dataset.spectra_files`. Кнопки «Select all» / «Deselect all».

**Identifications import type** — `ft.RadioGroup`:
- `ft.Radio(value="single", label="Single file")`
- `ft.Radio(value="per_sample", label="Per sample")`

Значение по умолчанию: `"single"` если файлов идентификаций ≤ 1 или единственный файл — всегда `"single"`. Если файлов идентификаций > 1, дефолт `"per_sample"`.

**Identifications parser** — `ft.Dropdown`:
- `MzTab` — доступен всегда
- `CasaNovo` — доступен только при режиме `"per_sample"`

При переключении режима пересчитывать доступные опции парсера.

**Tool name** — `ft.TextField`.

**Файлы идентификаций:**
- Режим `single`: один `ft.Dropdown` с файлами `.mztab`
- Режим `per_sample`: маппинг аналогичный `ImportMzTabDialog` — горизонтальный ряд с прокруткой. Для каждого выбранного спектрального файла — строка: `[имя спектрального файла] → [Dropdown выбора ident файла]`

**Import protein data** (чекбокс) — отображается только если в проекте есть FASTA (`len(await project.get_proteins(...)) > 0` или проверить через `project.get_protein_results_joined` — уточнить метод проверки наличия FASTA при реализации). При установке — скачиваем и импортируем FASTA-файлы из датасета.

**Import protein mapping** (чекбокс) — активен только если выбранный парсер поддерживает белки (т.е. не CasaNovo; проверять `parser_class.contain_proteins`). При установке — `collect_proteins=True`.

**Delete temp files** (чекбокс, по умолчанию True) — удалять скачанные файлы после импорта.

Кнопка «Import» — активна если: выбран subset, выбран хотя бы один спектральный файл, заполнено Tool name.

#### Экран прогресса

Аналог `_show_progress_screen` из `ImportMaxQuantDialog`:
- `ft.Text` — текущее сообщение
- `ft.ProgressBar`
- `ft.Text` — детали (stage)

Последовательные стадии: «Downloading files» → «Importing spectra» → «Importing identifications» → «Importing FASTA».

## 5. CLI: команда `pride`

### 5.1 Задача: добавить команду `pride` в `import_data.py`

**Файл:** `dasmixer-cli/src/dasmixer/cli/commands/import_data.py` (ИЗМЕНИТЬ)

```python
@app.command(name="pride")
def import_pride(
    project_path: str = typer.Argument(..., help="Path to .dasmix project file"),
    dataset_id: str = typer.Argument(..., help="PRIDE dataset accession, e.g. PXD000001"),
    tool_name: str = typer.Option("PRIDE Import", "--tool-name"),
    subset_name: str = typer.Option("PRIDE Import", "--subset-name"),
    spectra_parser: str = typer.Option("MGF", "--spectra-parser"),
    ident_parser: str = typer.Option("mzTab", "--ident-parser"),
    import_fasta: bool = typer.Option(False, "--import-fasta/--no-import-fasta"),
    collect_proteins: bool = typer.Option(False, "--collect-proteins/--no-collect-proteins"),
    delete_temp_files: bool = typer.Option(True, "--delete-temp-files/--keep-temp-files"),
):
    """
    Import a PRIDE dataset into a DASMixer project.

    Spectra and identification files are matched automatically via ms_run
    location from the mzTab file. If the project does not exist, it is created.

    Example:
        dasmixer-cli import pride project.dasmix PXD000001
    """
```

Логика:
1. Создать `PrideDataset(dataset_id)` — обработать `DasmixerNetworkException` и `PrideDatasetNotFoundException` с выводом ошибки и `raise typer.Exit(1)`
2. Открыть/создать проект
3. Получить или создать subset по `subset_name`
4. Маппинг по умолчанию — single file (первый `.mztab` файл) для идентификаций; все `.mgf` файлы для спектров
5. Сформировать `PrideImportOptions` и вызвать `run_pride_import`
6. Вывести итоги

## 7. Граничные случаи и замечания

- `PrideFile.download_file()` использует `skip_if_downloaded_already=True` — повторный запуск импорта не перекачивает файлы.
- `MzTabImporter` имеет `require_project=True` и `can_import_multifile=True` — резолвинг ms_run → spectra_file_id происходит внутри парсера через `resolve_spectra_file_by_location`.
- Список допустимых расширений (`allowed_spectra_extensions`, `allowed_ident_extensions`) хранится в `PrideDataset` — при добавлении новых парсеров достаточно расширить эти списки.
- Импорт табличных форматов (`.csv`, `.tsv`, `.xlsx`) намеренно не поддерживается.
- `pridepy` — опциональная зависимость; при попытке использовать PRIDE-импорт без установленного пакета должна выводиться понятная ошибка (`ImportError` с подсказкой установить `dasmixer-core[pride]`).
- В GUI проверять наличие `pridepy` при инициализации диалога (в `__init__` или `show()`), до обращения к сети.
