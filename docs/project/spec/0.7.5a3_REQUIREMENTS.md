# 0.7.5a3: доработки отображения графиков разметки пептидов и расчёта matching'а

## Определение пика прекурсора

Пик прекурсора определяется как пик любого типа ионов, последовательность которого соответствует всей последовательности для разметки. На графике могут получться несколько пиков прекурсора, с различными вариантами потерь.

Пики прекурсора на графике, независимо от исходного типа ионов, отображаются с контуром чёрного цвета. Подпись меняется с напр. y8+2 на P+2 (т.е. вместо типа ионов и порядкового номера отображаем букву "P").

В шаблоне hover'а первую строку делаем вида "y8-H2O PEPTIDEE (Precursor peak)". Для обычных пиков не добавляется " (Precorsor peak)"

## Расчёт параметров с поправкой на пик прекурсора

Пик прекурсора не должен учитываться при расчёте Quality, LCRR, peaks covered, top peaks covered. НО должен учитываться в Intensity Coverage и Unconfirmed PTMs.
