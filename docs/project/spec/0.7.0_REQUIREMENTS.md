# Доработки 0.7.0rc1

## Вкладка Export, общие параметры файлов

Добавить на вкладке Export, в самом верху блок Common Settings с двумя флагами:
- Add date and time to file name
- Overwrite existing files

Оба по умолчанию выставлены в True. Значения сохраняются в project_settings, автоматически при изменении.

Поведение выглядит очевидным, но проговорю:

если усановлен флаг Add date..., то в название экспортируемого файла (когда экспортируется пачка, без выбора конкретного пути к файлу, только к папке) добавляются текущие дата и время (текущая логика). Если не установлен, то в имя файла они не добавляются.

Если установлен Overwrite existing files - то не уведомляя пользователя перезаписываем существующие файлы при экспорте. Если не установлен - при наличии файла в целевом пути экспорта пропускаем. Экспортируем только те, которых ещё не было.
