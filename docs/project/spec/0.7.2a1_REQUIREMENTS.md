# 0.7.2a1: Расчёт Longest Consecutive Run Ratio (LCRR)

Longest Consecutive Run Ratio рассчитывается в рамках Ion Match (правка уже внесена в сам механизм расчёта в _match.py, функция Match predictions его уже возвращает (longest_consec_run_rate в классе MatchResult).

Это критерий максимальной выявленной последоватлеьности пиков одного типа в спектре поделенное на длину последовательности. Является косвенным показателем качества спектра 

Необходимо интегрировать этот параметр в БД, GUI и параметры инструмента.

- БД: добавляем поле lcrr (REAL, nullable) в таблицу identification (schema.py), увеличиваем PROJECT_VERSION до 0.7.2, создаём соответствующую миграцию
- При расчёте Coverage необходимо сохранять возвращаемое значение в поле lcrr
- В интерфейсе (вкладка Peptides), в параметрах инструмента (секция Preferred Settings) добавляем поле Min LCRR (по умолчанию 0.2)
- Учитываем lcrr при расчёте preferred
- Выводим в таблицу на вкладке Peptides под названием LCRR
