## Обзор

Версия 0.7.1a2 включает четыре независимых качественных улучшения GUI-приложения:

1. **Масштабирование графиков** — адаптация размера графиков под размер окна с настраиваемым aspect ratio
2. **Режим интерактивного просмотра** — переключатель между pywebview (Window) и браузером (Browser) для графиков и отчётов
3. **Название проекта в заголовках** — отображение имени открытого проекта в заголовке окна и AppBar
4. **Пункт меню "Open Recent"** — модальное окно для быстрого доступа к недавним проектам из системного меню

Все изменения локализованы в `dasmixer-gui` (GUI-слой) и `dasmixer-core` (конфигурация). Изменения в БД и API проекта не требуются.

## 1. Масштабирование графиков

### 1.1. Требования

- Добавить настройку **Plot aspect ratio** в Settings (Dropdown, значения: `"1:1"`, `"4:3"`, `"2:3"`, `"16:9"`)
- При отрисовке графиков в `BasePlotView` учитывать текущий размер окна (`page.window.height`) и выбранное соотношение сторон
- Высота графика вычисляется по формуле:
  ```python
  def get_plot_height(window_height: int) -> int:
      if window_height <= 430:
          return 300
      if window_height >= 1130:
          return 1000
      return window_height - 130
  ```
  (размер графика на 130px меньше окна, но не менее 300px и не более 1000px)
- Ширина графика = `int(height * (W / H))`, где `W:H` — выбранное соотношение (например, для `"4:3"` → `width = height * 4/3`)
- Автоматическая перерисовка при изменении размера окна **не требуется** — размер применяется при следующей генерации графика
- **Область действия:** только `BasePlotView` и его наследники (`PeptideIonPlotView`, `ProteinConcentrationPlotView`). `PlotlyViewer` (отдельный компонент для отчётов) и HTML-отчёты (`ReportViewer`) не затрагиваются.

```python
from dasmixer.api.config import config

def _get_plot_dimensions(page: ft.Page | None) -> tuple[int, int]:
    """
    Calculate plot width and height based on window size and aspect ratio setting.
    
    Returns:
        (width, height) tuple in pixels
    """
    # Default if page unavailable
    if page is None or page.window is None or page.window.height is None:
        return (1100, 700)
    
    window_height = page.window.height
    
    # Apply height formula
    if window_height <= 430:
        height = 300
    elif window_height >= 1130:
        height = 1000
    else:
        height = window_height - 130
    
    # Parse aspect ratio
    aspect_ratio_str = config.plot_aspect_ratio
    aspect_map = {
        "1:1": (1, 1),
        "4:3": (4, 3),
        "2:3": (2, 3),
        "16:9": (16, 9),
    }
    w, h = aspect_map.get(aspect_ratio_str, (16, 9))
    
    width = int(height * w / h)
    
    return (width, height)
```

def resume(self) -> None:
    """
    Restore the plot viewer.

    If _last_img_bytes is available, restores instantly (no Kaleido call).
    Otherwise schedules an async re-render.
    """
    if not self._is_suspended or self.current_figure is None:
        return
    self._is_suspended = False

    # Calculate dimensions based on current window size
    width, height = _get_plot_dimensions(self.page)

    if self._last_img_bytes is not None and self.preview_container is not None:
        viewer = PlotlyViewer(
            figure=self.current_figure,
            width=width,
            height=height,
            title=self.title,
            show_interactive_button=False,
            img_bytes=self._last_img_bytes,
        )
        self.preview_container.content = viewer
    elif self.page and self.current_entity_id:
        # No cached bytes — schedule async re-render
        self.page.run_task(self._generate_and_display_plot)
    # Caller handles page.update()
```

    import glob
    from pathlib import Path

    temp_dir = Path(tempfile.gettempdir())

def show_webview(fig: go.Figure, title: str):
    """
    Show plotly figure in webview window or browser based on config.
    
    Top-level function required for multiprocessing pickling.
    """
    from dasmixer.api.config import config
    
    html = fig.to_html(include_plotlyjs='cdn')
    
    if config.plot_view_mode == "Browser":
        import tempfile
        import webbrowser
        from pathlib import Path
        
        # Create temp file with delete=False so it survives browser open
        with tempfile.NamedTemporaryFile(
            mode='w',
            suffix='.html',
            prefix='dasmixer_plot_',
            delete=False,
            encoding='utf-8'
        ) as f:
            f.write(html)
            temp_path = f.name
        
        webbrowser.open(f'file://{Path(temp_path).as_posix()}')
    else:
        # Default: Window mode (pywebview)
        import webview
        window = webview.create_window(title, html=html)
        webview.start()
```

```python
"""Reusable component for displaying recent projects list."""

import flet as ft
from pathlib import Path


class RecentProjectsList(ft.Column):
    """
    Display list of recent projects with clickable tiles.
    
    Filters out non-existent files automatically.
    """
    
    def __init__(self, recent_projects: list[str], on_click_project):
        """
        Args:
            recent_projects: List of project file paths
            on_click_project: Callback(path: str) when project is clicked
        """
        super().__init__(spacing=5)
        self.recent_projects = recent_projects
        self.on_click_project = on_click_project
        self.controls = self._build_list()
    
    def _build_list(self) -> list[ft.Control]:
        """Build list of tiles for existing projects."""
        items = []
        for project_path in self.recent_projects:
            path = Path(project_path)
            if path.exists():
                items.append(
                    ft.ListTile(
                        leading=ft.Icon(ft.Icons.DESCRIPTION),
                        title=ft.Text(path.name, weight=ft.FontWeight.BOLD),
                        subtitle=ft.Text(str(path.parent), size=12),
                        on_click=lambda e, p=project_path: self.on_click_project(p),
                    )
                )
        
        if not items:
            items.append(
                ft.Text(
                    "No recent projects",
                    size=14,
                    italic=True,
                    color=ft.Colors.GREY_600,
                )
            )
        
        return items
```

## Риски и ограничения

1. **Масштабирование графиков:**
   - При очень маленьком окне (< 430px по вертикали) график будет 300×N, может выглядеть слишком мелко
   - Для portrait соотношения (2:3) при большой высоте width может превысить размер окна — переполнение по горизонтали (но это edge case, скроллинг решит)

2. **Режим Browser:**
   - Temp-файлы накапливаются при многократном открытии графиков без закрытия проекта (cleanup только при open/close/new project)
   - В режиме Browser нет управления жизненным циклом окна браузера (пользователь может закрыть вкладку, но файл останется до cleanup)
   - `webbrowser.open()` может открыть новую вкладку/окно в уже запущенном браузере — поведение зависит от ОС и настроек браузера

3. **Название проекта:**
   - Длинные имена файлов могут переполнить AppBar title — Flet автоматически обрежет, но визуально может быть некрасиво (ограничение не вводим, оставляем as-is)

4. **Open Recent:**
   - При большом количестве недавних проектов (до 10) модалка с фиксированной высотой 300px может потребовать скроллинга — это нормально, Flet добавит скролл автоматически

## Примечания для разработчика

1. **Import порядок:** При добавлении `from dasmixer.api.config import config` в `base_plot_view.py` убедиться, что не возникает циклических импортов (маловероятно, config — leaf-модуль)

2. **Multiprocessing и config:** Функции `show_webview()` и `_show_html_in_webview()` запускаются в отдельных процессах через `multiprocessing.Process` — доступ к `config` в дочернем процессе безопасен (config считывается заново из JSON-файла в каждом процессе при первом обращении)

3. **Page.window.height:** Значение может быть `None` при определённых условиях (окно ещё не инициализировано) — функция `_get_plot_dimensions()` обрабатывает этот случай с fallback на (1100, 700)

4. **Path.stem vs Path.with_suffix(''):** `Path.stem` корректно убирает расширение (`"project.dasmix"` → `"project"`), `with_suffix('')` не убирает, а заменяет суффикс на пустой (в исходных требованиях была ошибка, исправлено на `.stem`)

5. **Тестирование на Windows:** `webbrowser.open()` на Windows по умолчанию открывает Edge или Chrome (в зависимости от дефолтного браузера) — убедиться, что file:// URIs открываются корректно

6. **AlertDialog с asyncio.Event:** В методе `_show_open_recent_dialog()` не используется `asyncio.Event` для ожидания закрытия диалога (в отличие от паттерна в `_show_migration_dialog()`), потому что обработчик `on_project_selected` сам закрывает диалог и запускает `open_project()` асинхронно через `page.run_task()` — дополнительный wait не нужен
