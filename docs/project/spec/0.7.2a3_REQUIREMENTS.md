# 0.7.2a3: улучшение вывода графиков ионов

## Подзаголовки графиков

Требуется доработать логику формирования заголовков в графиках ионов.

ПОльзвоатель должен иметь выбор, какие параметры отображаются в заголовке subplot'а. Сейчас отображаются sequence, score, ppm, tool, is_preferred

Добавляем строку с checkbox'ми в plot_params для параметров (знаком "☑" обозначаю включённые по умолчанию, "☐" - выключенные)
- ☑ preferred
- ☑ tool
- ☑ sequence
- ☐ protein id
- ☐ gene
- ☑ identity
- ☐ ppm
- ☐ score
- ☐ intensity coverage # отображаем на графике: iC: {value:2f}
- ☐ quality # отображаем: Q: {value:2f}
- ☐ lcrr # LCRR: {value:2f}

Если значение параметра - null, или отсутствует в случае с matched_sequence (параметры качества сейчас не рассчитываются для matched sequence при неполном совпадении в белке), то параметр не отображаем в заголовке, даже если выбран

Доработки затрагивают:
- dasmixer-core/src/dasmixer/api/project/mixins/plot_mixin.py - логика формирования заголвоков, в метод `get_spectrum_plot_data` передаём список установленных чекбоксов
- dasmixer-gui/src/dasmixer/gui/views/tabs/peptides/peptide_ion_plot_view.py - view, здесь добавляем контролы и логику передачи параметров из контролов
