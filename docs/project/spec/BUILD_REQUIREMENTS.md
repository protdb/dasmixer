# Подготовка механизма сборки DASMixer

Реализуем один универсальный скрипт `build.py` на Python с использвоанием typer. Основные возможности:

- обновление версии (см. `build_tools/set_version.py`)
- сборка пакетов (см. `build_all.sh`)
- загрузка в PyPi, тест и прод - там же
- сборка под Windows: `pyinstaller dasmixer.spec --clean -y`
- компиляция установщика для Windows: `& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" dasmixer.iss`
- Архивирование инсталлера в .zip-архив для распространения тестировщикам
- Создание release в GitHub и загрузка установщика через Github CLI

## Внутренние команды build.py

### `build.py release <version>`

- Спрашивает: УВЕРЕНЫ, ЧТО ГОТОВЫ ВЫЛОЖИТЬ? (ну формулировка получше должна быть)
- обновляет версию на переданную как <version>
- собирает все четыре пакета (gui, cli, core, metapackage)
- если текущая платформа - Windows:
  - Собирает с помощью pyinstaller
  - Компилирует установщик
  - Создаёт tag и release
    - В описание release добавляет текст из docs/project/changes/v<version>.md
    - В release добавляет бинарный файл установщика: dist/setup/DASMixer<version>-setup.exe
    - Добавляет все три собранных пакета из соответствующих папок dist
- Загружает в тестовый PyPi
- Проверяет корректность загрузки, доступность версии
- Загружает в PyPi (прод)
- Выдаёт ссылки:
  - Релиз на GitHub
  - Релиз dasmixer на PyPi (прод)

Полностью падает при:
- ошибках сборки любого этапа
- отсутствии артефактов сборки хотя бы какого-то из этапов
- отсутствии changelog'а

Если версия не изменена (пользователь указал ту же версию, что была), то требует подтверждения

### `build.py internal [version]`
Здесь  версия опциональна. Работает только под Windows, в другой системе завершается с ошибкой
- Если версия передана, обновляет
- Собирает с помощью pyinstaller
- Компилирует установщик
- Упаковывает установщик в одноимённый .zip-архив

### `build.py pypi [version] [--prod]`
- собирает пакеты python
- загружает в Pypi (только test по умолчанию, на прод если есть флаг --prod)

### `build.py set-version <version>`
Только меняет все версии
