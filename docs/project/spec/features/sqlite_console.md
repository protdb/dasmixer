# Planned feature: SQLIte console

Концепция: включить в систему отдельный view для отладки, исправления ошибок и административного функционала, а также тонкой настройки через встроенную консоль SQLite

## Внешний вид

Добавляется пункт в меню параметров SQLite console. Он открывает отдельный View, состоящий из двух основных элементов:
- Окно диалога: запросы пользователя, результаты выполнения запросов
- Поле ввода: многострочный ввод с кнопкой "RUN" справа. Т.е. оформление аналогично чату.

Окно консоли строится также аналогично чату. Запросы пользвоателя центрируются к правому краю, результаты выполнения центрируются к левому

Результаты могут быть трёх видов:
- Успешное выполнение: зеленый фон, сообщение SQLite: кол-во измененных строк, время выполнения
- Ошибка: красный фон, описание ошибки
- Возвращенные данные: таблица. ВЫывод обрезается до 10 строк, добавляется горизонтальная прокрутка и кнопка "Скачать", по которой скачивается csv/xlsx файл с результатом запроса
