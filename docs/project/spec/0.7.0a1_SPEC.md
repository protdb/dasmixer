|---|---|
| Образец есть и в файле, и в проекте | `Colors.GREEN_100` (зелёный) |
| Образец есть только в проекте | `Colors.AMBER_100` (жёлтый) |

По нажатию «Preview»:
1. Получаем список имён образцов из проекта: `await project.get_samples()` → `{s.name for s in samples}`
2. Читаем колонку из DataFrame: `file_names = set(df[selected_column].astype(str))`
3. Строим объединение для отображения

По нажатию «Import»:
- Проходим по зелёным образцам (пересечение)
- Для каждого: берём строку из df, где `df[column] == sample.name`
- Преобразуем в dict: `row_dict = row.to_dict()` (типы — как в pandas, числа остаются числами)
- Загружаем образец: `sample = await project.get_sample_by_name(name)` (см. п. 3.3)
- Сливаем additionals: если `sample.additions` не `None` и не пустой — делаем `merged = {**sample.additions, **row_dict}`, иначе `merged = row_dict`
- Обновляем: `sample.additions = merged; await project.update_sample(sample)`
- После всех образцов: `await project.save()`
- Показываем snackbar с итогом: «Additional data imported for N sample(s)»

> **Важно:** Обработка образцов **поштучно** (не batch). Образцы из файла, которых нет в проекте — игнорируются. Образцы в проекте без данных в файле — пропускаются.

#### Логика выбора оптимального источника концентрации

При `absolute_concentrations='all'` sempai возвращает колонки:
- `*_abs_total_gl`, `*_abs_total_mol` — через `C_total`
- `*_abs_albumin_gl`, `*_abs_albumin_mol` — через `C_ref`

Выбор **предпочтительного** источника по методу (согласно `LFQ_abs.md`):

| Метод | Предпочтительный источник | Запасной |
|---|---|---|
| emPAI | `total` | `albumin` |
| NSAF | `total` | `albumin` |
| iBAQ | `albumin` | `total` |
| Top3 | `albumin` | `total` |

Алгоритм для каждого алгоритма `alg` и строки результата:
```python
preferred = 'total' if alg in ('emPAI', 'NSAF') else 'albumin'
fallback = 'albumin' if preferred == 'total' else 'total'

# g/l
val_gl = row[f'{alg}_abs_{preferred}_gl']
if pd.isna(val_gl):
    val_gl = row.get(f'{alg}_abs_{fallback}_gl')

# mol/l
val_mol = row[f'{alg}_abs_{preferred}_mol']
if pd.isna(val_mol):
    val_mol = row.get(f'{alg}_abs_{fallback}_mol')
```

`calculate_lfq` возвращает DataFrame с колонками:

```
protein_identification_id | algorithm | rel_value | abs_value_gl | abs_value_mol
```

`abs_value_gl` и `abs_value_mol` = `None` если `abs_enabled=False` или нет данных.

### 5.3 Top3: возврат `None` при < 3 пептидах

**Файл:** `dasmixer-core/src/dasmixer/api/calculations/proteins/sempai/algorithms.py`

Функция `calculate_top3_value(intensities: list[float]) -> float | None`:

```python
def calculate_top3_value(intensities: list[float]) -> float | None:
    """
    Возвращает среднее трёх наиболее интенсивных пептидов.
    Возвращает None если пептидов меньше 3.
    """
    if len(intensities) < 3:
        return None
    top3 = sorted(intensities, reverse=True)[:3]
    return sum(top3) / 3
```

Аналогично в классе `Protein` (`protein.py`) — свойство / метод вычисления Top3 должно возвращать `None` при < 3 пептидах.

## 6. LFQ: сохранение результатов квантификации

### 6.1 Исправление логики удаления перед пересчётом

**Файл:** `dasmixer-core/src/dasmixer/api/project/mixins/protein_mixin.py`

**Текущее поведение** (неверное): при расчёте LFQ удаляются ВСЕ квантификации для образца.  
**Требуемое поведение:** удалять только записи с тем же `algorithm`, что пересчитывается.

Добавить метод:

```python
async def clear_protein_quantifications_for_sample_and_algorithm(
    self, sample_id: int, algorithm: str
) -> None:
    """
    Удаляет записи protein_quantification_result для конкретного образца и алгоритма.
    """
    await self._execute("""
        DELETE FROM protein_quantification_result
        WHERE id IN (
            SELECT pqr.id
            FROM protein_quantification_result pqr
            JOIN protein_identification_result pir ON pqr.protein_identification_id = pir.id
            WHERE pir.sample_id = ? AND pqr.algorithm = ?
        )
    """, (sample_id, algorithm))
```

В `LFQAction.run()` — перед расчётом для каждого образца и каждого метода вызывать:
```python
for method in selected_methods:
    await project.clear_protein_quantifications_for_sample_and_algorithm(
        sample_id, method
    )
```

```python
class LFQSelector(SelectorBase):
    """
    Составной компонент для выбора LFQ-метода и типа значения.
    
    Состоит из:
    - Dropdown: выбор алгоритма (emPAI / iBAQ / NSAF / Top3)
    - RadioGroup: rel / g/l / mol/l
    
    Возвращает tuple[str, str]:
        - [0]: алгоритм ('emPAI', 'iBAQ', 'NSAF', 'Top3')
        - [1]: имя колонки в БД ('rel_value', 'abs_value_gl', 'abs_value_mol')
    """
    
    def __init__(
        self,
        label: str = "LFQ",
        default_method: str = "emPAI",
        default_value_type: str = "rel",  # 'rel' | 'gl' | 'mol'
    ):
        ...
    
    def build(self) -> ft.Control:
        """Строит Dropdown + RadioGroup."""
        ...
    
    def get_value(self) -> tuple[str, str]:
        """Возвращает (algorithm, column_name)."""
        col_map = {
            "rel": "rel_value",
            "gl":  "abs_value_gl",
            "mol": "abs_value_mol",
        }
        return (self._method_dropdown.value, col_map[self._value_radio.value])
```
