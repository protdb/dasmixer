# Промежуточная задача: очистка кода, выявление проблемных мест

## Удаление dead code

### GUI

В dasmixer-gui есть несколько версий tab'ов, ряд диалогов может дублироваться. Необходимо очистить устаревшие файлы из струкутры проекта, они зачастую только отвлекают и находятся в ненужных индексах. Их удаляем спокойно

Также необходимо убедиться, что все процессы действительно единообразны, в частности процессы, запускаемые с manage samples view должны быть аналогичны процессам, запускаемым с samples tab/ peptide tab

### CLI

Убедиться, что процессы, запускаемые из CLI, синхронны процессам GUI на уровне вызовов api, т.е. не должно быть ситуаций, когда на один и тот же процесс из CLI вызывается один метод, из GUI - другой. Такие случаи вызова устаревших методов есть в импортах

### Core

Отследить процессы, вызываемые GUI и CLI, на предмет дупликатов входных точек, выявить и выписать неиспользуемые методы и модули, в частности вызовы Mixin'ов Project'а.

Тут важно:
- Удалять: явно устаревшие модули, не вызываемые нигде в проекте, если присутствует явный дупликат
- Сомнительные вещи описывать и отмечать

## AGENTS.md

Требуется провести review AGENTS.md, уточнить в нём информацию о структуре проекта, добавить важные моменты:
- Формат changelog'ов. Changelog пишется/дополняется по команде от разработчика
- Агент не должен сам менять версии в коде, за исключением PROJECT_VERSION, что запрашивается в явном виде в требованиях. Версии меняются в пайплайне build.py
