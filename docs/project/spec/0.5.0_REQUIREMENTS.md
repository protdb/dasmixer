# 0.5.0, разделение на подпакеты

Необходимо выполнить преобразования файловой структуры (не логики!) и разделение зависимостей.

Проект должен разделиться:
- метапакет dasmixer
- пакет dasmixer-core, включает работу с проектом и вычислительный функционал (внутренний модуль API).
  - Опиционлаьная зависимость: plotly+kaleido `dasmixer-core[plotly]`
  - Опционлаьная зависимость: npysearch `dasmixer-core[proteins]`
  - Поная версия: `dasmixer-core[all]`
- пакет dasmixer-gui, включает GUI и зависимость от flet. Также включает typer, но позволяет только запустить GUI или открыть файл проекта в GUI
- пакет dasmixer-cli, включает все расширенные команды.

Принципальный моменты:
- Reports: входит в core (api), но есть важный нюанс касающийся иконок: сейчас используется исходный класс fi.Icons, но при установке только core/cli нет зависимости от Flet. Нужно сделать собственный mock-объект icons на уровне BaseReport и переписать существующие ссылки на него через условный
- сборка под windows (dasmixer.spec) пока остаётся для полного приложения и только для него
- Струкутру меняем минимально (в core идёт dasmixer.api без переименования).
- Оставляем логику монорепозитория
- Версионирование держим синхронным. Сейчас всё (core, api, gui, метапакет dasmixer) должно быть версии 0.5.0 и иметь зависимости сторого от версии 0.5.0 друг друга
- Добавь скрипт сборки: собрать все пакеты, получить подтверждение от пользователя, что всё ок; залить на тестовый pypi, получить подтвереждение; залить на продовый pypi.


Учитывай, что в git это всё ещё монорепозиторий и разработка идёт также для всех пакетов синхронно из общей директории (как сейчас)
