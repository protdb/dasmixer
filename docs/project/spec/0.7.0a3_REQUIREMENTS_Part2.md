# 0.7.0a3, Параллельный расчёт LFQ

При расчёте LFQ на вкладке Peptides сейчас вычисления идут в один поток. На большом числе образцов это неэффективно.

Нужно сделать параллельный расчёт с использованием CPU (см. настройки количества ядер CPU для расчётов). Т.е. один поток одновременно вычисляет величины для одного файла, одновременно обсчитывается количество идентификаций по числу образцов

Данные из БД при этом получаем Batch'ами
