## Масштабирование графиков

Для отображения графиков, которые отображаются в GUI, BasePlotView:

Выносим в настройки параметр plot aspect ratio (dropdown), возможные значения:
- 1:1
- 4:3
- 2:3
- 16:9

При отрисовке графиков (BasePlotView) учитываем размер экрана и соотношение. Высота графика должна определяться следующим образом:
```python
def get_plot_height(window_height: int) -> int:
    if window_height <= 430:
        return 300
    if window_height >= 1130:
        return 1000
    return window_height - 130
```

т.е. размер графика должен быть меньше размера окна на 130px (примерная высота статичной части с заголовком и вкладками), но не менее 300px и не более 1000px

Автоматическая перерисовка при изменении размера окна не требуется, но если размеры были изменены, то следующий график генерируется в новых размерах

## Режим интерактивного просмотра

Требуется сделать переключатель механизма интерактивного просмотра для графиков и отчётов. Переключатель выносится в настройки, называем: Plot and report view mode. Это должен быть Dropdown с вариантами Window, Browser. Текущая логика с pywebview соответствует режиму Window и не меняется.

Если выбран режим Browser, то генерируемую web-страницу (и в случае отделнього графика через plotly, и в случае отчёта, содержащего несколько графиков) сохраняем в temp (через os.gettempdir) и открываем в браузере по умолчанию.
