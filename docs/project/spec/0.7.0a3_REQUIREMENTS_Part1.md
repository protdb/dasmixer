# 0.7.0a3, доработки формы инструмента и нижележащей логики

# Улучшение секции параметров инструмента

Форму параметров инструмента (`dasmixer-gui/src/dasmixer/gui/views/tabs/peptides/tool_settings_section.py`) необходимо доработать:

## Разделение формы на секции

Верхняя секция без подзаголовка, четыре чекбокса по два в строке:
- Trust all identifications
- Trust PPM (новый флаг, ниже будет описание логики)
- Use protein ID from file
- Recalculate PTMs (по умолчанию ВКЛ)

Следующий блок: Preferred settings:
- Max PPM, Min Score, Min ion Coverage
- Min peptide length, Max peptide length
- Min Top-10 peaks covered, Min ions covered, Min spectrum peaks
- De novo correction

Следующий: PTM
- Max PTM combinations
- Select PTMs...

Следующий: Protein search
- Min protein identity, I/L Combinatorics (переименовываем Use Leucine combinatorics)
- Match Correction Criteria
- Save AA Substitutions

##  Блокировка параметров по чекбоксам заголовка

Контролы в заголовке (кроме Trust PPM) блокируют все контролы в связанной секции

- Trust all identifications: если установлен, блокирует всю секцию Preferred settings
- Use protein ID from file: блокирует Protein search
- Recalculate PTMs: если установлен, блокирует PTM

## Логика Trust PTM:

Если этот флаг установлен, то в случае если для идентификации есть не null значение ppm, оно не перезаписывается и не вычисляется: доверяем величине, полученной при импорте из файла идентификаций

## Логика Recalculate PTMs

Если этот флаг установлен, то не перебираем варианты PTM и используем при сопоставлении и других расчётах только те, которые есть в исходной последовательности.

Нюанс: если в последовательности есть PTM с не фиксированной позицией (см. `docs/project/changes/v0.7.0a2.md`), то перебираем ТОЛЬКО эти вариабельные PTM. Это, скорее всего, потребует модификации в SeqFixer
