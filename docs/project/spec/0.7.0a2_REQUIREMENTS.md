# Доработки 0.7.0a2, экспорт MGF

## Улучшение экспорта MGF

Текущая проблема: при экспорте MGF сохраняются не все поля.

Исходный файл .MGF:

```
BEGIN IONS
INSTRUMENT=ESI-TRAP
PEPMASS=855.3673 730.0
CHARGE=1+
TITLE=LEPeakID:1:_AVERAGE_CHARGE=1.0:_DRIFT_TIME_IN_BINS=103.57628
RTINSECONDS=67.69923
430.2171 79.0 1.0
578.3363 128.0 1.0
599.08136 47.0 1.0
674.3343 72.0 1.0
750.30493 37.0 1.0
750.3434 26.0 1.0
839.35004 41.0 1.0
845.3729 987.0 1.0
847.4188 90.0 1.0
853.39526 50.0 1.0
END IONS

```

В БД, таблица spectre, поле all_params:

```json
{"mass": "Monoisotopic", "_spectrum_type": "Electrospray-Shotgun", "instrument": "ESI-TRAP", "pepmass": [817.3723, 1398.0], "charge": [1], "title": "LEPeakID:1:_AVERAGE_CHARGE=1.0:_DRIFT_TIME_IN_BINS=95.05456", "rtinseconds": 68.50712}
```

В экспортированном файле:

```
BEGIN IONS
TITLE=LEPeakID:1:_AVERAGE_CHARGE=1.0:_DRIFT_TIME_IN_BINS=103.57628
PEPMASS=855.3673
CHARGE=1+
430.2171 79.0 
578.3363 128.0 
599.08136 47.0 
674.3343 72.0 
750.30493 37.0 
750.3434 26.0 
839.35004 41.0 
845.3729 987.0 
847.4188 90.0 
853.39526 50.0 
END IONS

```

Т.е.:
- Теряется заряд на каждый из пиков. В исходном файле он указан некорректно (как float, а не как целое число, это часть проблем формата PLGS, отсюда отдельный парсер для него).
- Теряется все дополнительная информация из параметров. Она есть в all_params, но отсутствует в выводе. В том числе важная информация, такая как интенсивность, retention time (pepmass[1], rtinseconds и т.д.)
- Всё ещё учитываем здесь формат PEPMASS, когда сохраняются в одном поле через пробел, собственно, pepmass и intensity
- Также нужно:
  - При отсутствии в all_params - использовать значение scans из БД (для тех же PLGS-спектров сюда прописывается значение LePeakID при импорте - при экспорте хорошо бы указать в SCANS)
  - Если выбран при экспорте флаг "Write SEQ from identification" - параметр заголовка SEQ перезаписывается значением из идентификации (т.е. если он есть в all_params, то перезаписывается новым значением). Если на конкретный спектр нет ни одной (подходящей) идентификации, исходное значение остаётся.
  - Добавлять в начале файла комментарий: "# Exported from DASMixer"
