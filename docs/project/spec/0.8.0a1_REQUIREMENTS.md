# 0.8.0a1 - пересмотр структуры вкладок GUI

В текущей реализации есть, помимо прочего, две вкладки: Peptides и Proteins. На каждой из них есть:
- Параметры запуска расчётов
- Кнопки для запуска процессов
- Табличное представление данных с возможностью отрисовки графиков

Из-за этого возникает путаница, особенно в части процессов, которые опираются на результаты друг друга - часть требует перезапуска, часть нет.

Поэтому требуется создать три отдельные вкладки:
- Parameters: все настройки расчётов в одном месте, сгруппированные по процессам
- Calculations: Запуск всех процессов, журнал, подсказки по изменяющимся параметрам
- Results: Все табличные представления, построение графиков

В системе у нас есть несколько процессов, не связанных с импортом, в штатном варианте порядок процессов такой:
- Match proteins: поиск совпадения последовательностей в белках для identifications
- Calculate Ion coverage: расчёт физических показателей пептида, соответствие спектру
- Select preferred: выбор оптимальных идентификаций, в том числе при наличии нескольких идентификаций на один спектр
- Calculate protein identification: вычисление идентификаций белков в образце на основании мэппинга пептидов
- Label-Free Quantification: расчёт относительных концентраций белков в образце
- Enrich protein data : обогащение записей о белках данными из UniProt
