# 0.7.4a4 часть вторая: конфигурация временной директории и внутренний рефакторинг

Сейчас в системе есть логика определения временных папок для HTML, для MaxQuant, для PXD, являющийся платформозависимым, в них дублируется значительная часть кода, управления им нет.

Требуется добавить ряд функционлаьных возможностей для пользователя по настройке этого параметра, а также возможность очистить временные файлы.

В конфигурацию добавляем два параметра:
- tempdir
- large_file_tempdir

По умолчанию они настраиваются так же, как сейчас, т.е. работает платформозависимая логика, при создании файла конфигурации получаем подходящее значение для платформы. Также по умолчанию - значения одинаковые

в конфиг добавляем функцию
```python
def get_tempdir(self, dir_type: Literal['HTML', 'PXD', 'MaxQuant', 'root', 'large_root'] = 'root') -> Path:
    ...
```

dir_type = root возвращает просто tempdir. large_root - large_file_tempdir. Во вторую складываются 

Она должна возвращать корректную директорию, с учётом постфикса. Все постфиксы берем из текущих функций.

Имеющиеся функции отмечаем как Deprecated, но не удаляем. Логику в них меняем: пусть вызывают config.get_tempdir() с подходящим dir_type

На странице конфигурации в GUI добавляем две строки:
- Temporary files directory
- Temporary large files directory

Каждая состоит из следующих элементов:
- Текстовое поле (редактируемое) с текущим значением параметра
- Кнопка Browse (выбор папки, указание пути)
- Кнопка Open (открывает папку)
- Кнопка Clear (удаляет всё содержимое папки)

При нажатии на Clear - окно с подствеждением: пользователь должен явно подтвердить, что хочет очистить временную папку и что все лежащие там файлы будут удалены. Две кнопки - Ок/Отмена, если "Ок" - удаляем всё содержимое папки
