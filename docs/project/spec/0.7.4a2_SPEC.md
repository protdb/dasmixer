### 0.5. Мультиимпорт
- Парсер mzTab реализует множественный импорт: один файл → несколько
  `spectre_file`. Привязка — по `ms_run[N]-location`.
- Нормализация location: убрать `file://`, заменить `\` на `/`, взять
  `basename`, отбросить расширение; сравнение с `basename(stem)` путей
  `spectre_file` регистронезависимо. При отсутствии соответствия — строки
  этого `ms_run` **пропускаются** (лог warning).
- На каждый сопоставленный `ms_run` создаётся отдельная запись
  `identification_file` (одинаковый `file_path`); правило дубликатов
  применяется сразу ко всем составным файлам.
- Если `ms_run` ровно один и в диалоге уже выбран `spectra_file_id` —
  location игнорируется, используется выбранный файл (для CasaNovo,
  single-sample mzTab).
- GUI: новый режим импорта (флаг `can_import_multifile`), отдельный
  обработчик/диалог; пайплайн строится по образцу
  `run_maxquant_import` / step 7.

### 0.6. Модификации mzTab
- Список модификаций строится из MTD один раз (fixed + variable вместе,
  обработка универсальная) → `dict[identifier → proforma_tag]`.
  MTD-значения читаем из **сырых** строк (pyteomics теряет accession,
  см. §3.2).
- `UNIMOD:<id>` → `u.by_id(id)['title']` (Unimod инициализируется один
  раз, `self.unimod`); при отсутствии в MTD-кэше — прямой резолв.
- `CHEMMOD:<mass>` → `[+<mass>]` (знак сохраняется, напр. `[-18.0913]`).
- `MOD:<id>` → `[PSI-MOD:<id>]`, цифры в оригинальном количестве.
- Формат итоговой последовательности — через
  `pyteomics.proforma.parse` / `to_proforma`; `n_term`, `c_term`,
  `unlocalized_modifications` — списки (или `None`).
- Вероятности и любые данные из `[...]` отбрасываем. При нескольких
  позициях (`3|4|8`) — **одна** модификация уходит в
  `unlocalized_modifications` без позиции.
- Known issue (принимаем осознанно, не решаем): ion match / отрисовка
  графиков (другая библиотека) и расчёт массы для `PSI-MOD` могут
  работать нестабильно.

### 0.7. Форматы PSM (подтверждено на примерах)
- `spectra_ref`: `ms_run[8]:scan=22330`, `ms_run[8]-scan=24674`,
  `ms_run[1]:index=0`. `index=` → маппинг по `seq_no`, `scan=` → по
  `scans` (определяется по первой строке).
- `sequence` — немодифицированная; модификации в `modifications`.
- `search_engine_score[1]` → `score` (колонка может отсутствовать).
- `ppm`: **нельзя** считать наивно как
  `(exp - calc)/calc*1e6` — проверка примеров показала, что колонка
  `calc_mass_to_charge`, которую отдаёт pyteomics, в этих файлах
  **неконсистентна** (в SINGLE/MULTI там иногда заряд-нормированная или
  просто битая величина: ср. `LLPVQENFLLK z=3 exp=1772.10911
  calc=591.37439`, тогда как истинный m/z = 438.599). Поэтому:
  `charge` берём из соответствующей колонки, `ppm` считаем через
  нейтральную массу последовательности:
  `theor_mz = (theor_mass(ProForma) + charge*PROTON_MASS)/charge`,
  `ppm = (exp_mass_to_charge - theor_mz)/theor_mz*1e6` (`utils.ppm`).
  Это согласовано с расчётом downstream-пайплайна (`coverage_worker.py`
  считает ppm из `pepmass`+`charge`, а не из заявленных колонок).
  При наличии корректного `calc_mass_to_charge` он может быть
  sanity-check'ом (warning при сильном расхождении), но не источником.
- Белки: `contain_proteins=True`, `src_file_protein_id` из `accession`,
  Protein(id=accession). Одинаковые `PSM_ID` на нескольких строках
  схлопываем (join accession через `;`), как в PLGS `prepare_df`.
- `null` → `None`.

async def get_spectra_idlist(self, spectra_file_id: int, by: str = "seq_no"):

    if by == "title":

## 2. LASTRUN_VERSION и расширение PTM-CSV

### 2.1. `dasmixer/utils/ptm_config.py` — новые функции

```python
LAST_RUN_VERSION_FILENAME = "LASTRUN_VERSION"

def get_lastrun_version_path() -> Path:
    return Path(typer.get_app_dir("dasmixer")) / LAST_RUN_VERSION_FILENAME

def ensure_ptm_files() -> tuple[Path, Path]:
    """Гарантирует существование CSV (создаёт из DEFAULT_* при отсутствии)."""
    return _ensure_all_ptm_config_file(), _ensure_import_ptm_renames_file()

def _read_lastrun_version() -> str | None:
    p = get_lastrun_version_path()
    return p.read_text(encoding="utf-8").strip() if p.exists() else None

def _write_lastrun_version() -> None:
    get_lastrun_version_path().write_text(APP_VERSION, encoding="utf-8")

def merge_ptm_renames() -> int:
    """Дополняет import_ptm_renames.csv строками DEFAULT_PTM_RENAMES,
    отсутствующими по паре (parser, source). Возвращает число добавленных."""
    path = _ensure_import_ptm_renames_file()
    existing = load_ptm_renames()  # или чтение файла напрямую
    keys = {(r["parser"], r["source"]) for r in existing}
    added = 0
    with open(path, "a", newline="", encoding="utf-8") as f:
        w = csv.writer(f)
        for source, proforma, parser, is_terminal in DEFAULT_PTM_RENAMES:
            if (parser, source) in keys:
                continue
            w.writerow([source, proforma, parser, "Y" if is_terminal else "N"])
            added += 1
    return added

def merge_ptm_config() -> int:
    """Дополняет all_ptm_config.csv строками DEFAULT_PTM_CONFIG,
    отсутствующими по name. Возвращает число добавленных."""
    path = _ensure_all_ptm_config_file()
    existing_names = {r["name"] for r in load_ptm_config()}
    added = 0
    with open(path, "a", newline="", encoding="utf-8") as f:
        w = csv.writer(f)
        for name, attach_to, mono_mass, n_term, c_term, is_default in DEFAULT_PTM_CONFIG:
            if name in existing_names:
                continue
            w.writerow([
                name,
                ";".join(attach_to) if attach_to else "",
                "" if mono_mass is None else mono_mass,
                "Y" if n_term else "N",
                "Y" if c_term else "N",
                "Y" if is_default else "N",
            ])
            added += 1
    return added

def _refresh_caches() -> None:
    load_ptm_config.cache_clear()
    load_ptm_renames.cache_clear()
    try:
        from dasmixer.utils.seqfixer_utils import reload_ptms
        reload_ptms()
    except Exception:
        logger.exception("reload_ptms failed")

def check_and_update_ptm_config() -> None:
    """GUI startup: ensure CSV → если LASTRUN == APP_VERSION, выйти →
    иначе merge обоих файлов, обновить LASTRUN, сбросить кэши."""
    ensure_ptm_files()                       # ДО проверки LASTRUN
    if _read_lastrun_version() == APP_VERSION:
        return
    merge_ptm_renames()
    merge_ptm_config()
    _refresh_caches()
    _write_lastrun_version()

def update_ptm_list() -> tuple[int, int]:
    """CLI: всегда merge (идемпотентно) + обновить LASTRUN + сбросить кэши."""
    ensure_ptm_files()
    r = merge_ptm_renames()
    c = merge_ptm_config()
    _refresh_caches()
    _write_lastrun_version()
    return r, c
```

### 3.2. Чтение MTD (сырые строки)

MTD читаем **сами** линейно (до первой не-`MTD` строки), т.к.:
- pyteomics теряет accession модификаций (`UNIMOD:7` → `'Deamidated'`);
- свойство `mz.metadata`-based `ms_runs` падает на варианте
  `ms_run[N]_location` (MULTIFILE).

Из MTD извлекаем:
- `ms_run[N]-location` и `ms_run[N]_location` → `dict[int, str]`;
- `fixed_mod[i]` и `variable_mod[i]` → сырые `[CV, accession, name, value]`.

Хелпер:

```python
_MOD_PARAM_RE = re.compile(r"^\s*\[\s*([^,]*),\s*([^,]*),\s*([^,]*),\s*([^\]]*)\]\s*$")

def _read_mtd(self) -> None:
    self.ms_run_locations: dict[int, str] = {}
    raw_mods: list[str] = []
    with open(self.file_path, "r", encoding="utf-8", errors="replace") as f:
        for line in f:
            if not line.startswith("MTD"):
                break
            parts = line.rstrip("\r\n").split("\t")
            if len(parts) < 3:
                continue
            key, value = parts[1], parts[2]
            m = re.match(r"ms_run\[(\d+)\][-_]location$", key)
            if m:
                self.ms_run_locations[int(m.group(1))] = value
                continue
            if key.startswith("fixed_mod[") or key.startswith("variable_mod["):
                raw_mods.append(value)
    self._build_mod_tags(raw_mods)
```

### 3.3. Построение списка модификаций (rename map)

```python
def _build_mod_tags(self, raw_mods: list[str]) -> None:
    self._mod_tags: dict[str, str] = {}
    for raw in raw_mods:
        m = _MOD_PARAM_RE.match(raw)
        if not m:
            continue
        cv, accession, name, _value = (x.strip() for x in m.groups())
        accession = accession.strip()
        if not accession:
            continue
        self._mod_tags[accession] = self._to_proforma_tag(accession, name)
```

Резолв тега:

```python
def _to_proforma_tag(self, accession: str, name: str = "") -> str:
    if accession.startswith("UNIMOD:"):
        if name:
            return name                                  # имя из MTD
        uid = int(accession.split(":", 1)[1])
        return self.unimod.by_id(uid)["title"]           # fallback через Unimod
    if accession.startswith("MOD:"):
        return "PSI-MOD:" + accession.split(":", 1)[1]
    if accession.startswith("CHEMMOD:"):
        mass = accession.split(":", 1)[1]
        return mass if mass.startswith(("-", "+")) else "+" + mass
    return accession
```

`self.unimod = Unimod()` — инициализируется **лениво** и один раз
(сеть; при недоступности — исключение, режим offline в перспективе).
Для строк с идентификатором вне MTD-кэша — прямой резолв тем же методом
(ленивое создание `self.unimod`).

### 3.4. Сборка последовательности

Каноническая последовательность вынесена в отдельный метод (для
переопределения в CasaNovo/Pi-PrimeNovo):

```python
def get_canonical_sequence(self, row: dict) -> str:
    return "".join(aa for aa, _ in parse(row["sequence"])[0])
```

Общая сборка ProForma (база; вход — `sequence` + строка `modifications`):

```python
def get_modified_sequence(self, seq: str, mods: str) -> str:
    pf_seq, params = parse(seq)
    if not mods:
        return to_proforma(pf_seq, **params)
    params.setdefault("n_term", [])
    params.setdefault("c_term", [])
    params.setdefault("unlocalized_modifications", [])
    n = len([1 for aa, _ in pf_seq])
    for position_part, ident in self._iter_mod_items(mods):
        tag = self._mod_tags.get(ident) or self._to_proforma_tag(ident)
        positions = position_part.split("|")
        if len(positions) > 1 or positions[0] in ("null", ""):
            params["unlocalized_modifications"].append(GenericModification(tag))
            continue
        pos = int(positions[0])
        if pos == 0:
            params["n_term"].append(GenericModification(tag))
        elif pos == n + 1:
            params["c_term"].append(GenericModification(tag))
        else:
            idx = pos - 1
            aa, mods_list = pf_seq[idx]
            mods_list = (mods_list or [])
            mods_list.append(GenericModification(tag))
            pf_seq[idx] = (aa, mods_list)
    return to_proforma(pf_seq, **params)

@staticmethod
def _iter_mod_items(mods: str):
    """Разбирает строку modifications в (position_part, identifier).

    Коммы внутри [...] (вероятности) отбрасываются вместе со скобками."""
    cleaned = re.sub(r"\[[^\]]*\]", "", mods)   # выкидываем параметры
    for item in cleaned.split(","):
        item = item.strip()
        if not item or "-" not in item:
            continue
        position_part, ident = item.split("-", 1)
        ident = ident.split("|")[0].strip()
        yield position_part.strip(), ident
```

Проверено на логике: `to_proforma(parse('CKHPEAK')[0], n_term=[...])`
даёт `[Carbamyl]-C[Carbamidomethyl]KHPEAK`; `GenericModification('+113.08406')`
→ `[+113.08406]`, `GenericModification('PSI-MOD:00815')` →
`[PSI-MOD:00815]`.

### 3.5. Разбор PSM и `spectra_ref`

- Источник строк: `MzTab(path, table_format="raw")["PSM"]` → `.header`
  (`list[str]`) и `.rows` (`list[list]`). Batch-итерация — срез по
  `batch_size` (файл в память уже загружен pyteomics целиком; срез даёт
  совместимый с пайплайном интерфейс).
- Определение поля маппинга: по первой непустой `spectra_ref`:
  - содержит `index=` → `self.spectra_id_field = "seq_no"` (значение как
    есть; `index` 0-базовый совпадает с `spectre.seq_no`);
  - содержит `scan=` → `self.spectra_id_field = "scans"`.
- Парсер `spectra_ref`:

```python
_SPECTRA_REF_RE = re.compile(r"ms_run\[(\d+)\]\s*[:\-]\s*(scan|index)=(\d+)")

def _parse_spectra_ref(self, ref: str) -> tuple[int | None, str | None, int | None]:
    """Возвращает (ms_run_index, kind, value). Берётся первая ссылка при '|'."""
    if not ref:
        return None, None, None
    first = ref.split("|")[0]
    m = _SPECTRA_REF_RE.search(first)
    if not m:
        return None, None, None
    return int(m.group(1)), m.group(2), int(m.group(3))
```

- Колонки PSM → результат:
  - `score` ← `search_engine_score[1]` (если есть);
  - `ppm` ← расчёт от нейтральной массы ProForma и `charge`
    (см. §0.7); поле `charge` из PSM-строки;
  - `src_file_protein_id` ← `accession` (`null` → `None`);
  - `spectra_file_id` и `ms_run_index` — резолв (см. 3.6);
  - `sequence` (ProForma), `canonical_sequence`.

### 3.6. Резолв `ms_run` → `spectre_file` и схлопывание белков

Нормализация location (утилита в `dasmixer/utils/ident_spectra_pairing.py`):

```python
def normalize_spectra_location(location: str) -> str:
    s = location.strip()
    if s.lower().startswith("file://"):
        s = s[7:]
    s = s.replace("\\", "/")
    return Path(s).stem.lower()

def resolve_spectra_file_by_location(
    location: str, spectra_files: pd.DataFrame
) -> int | None:
    target = normalize_spectra_location(location)
    for _, row in spectra_files.iterrows():
        if Path(str(row["path"]).replace("\\", "/")).stem.lower() == target:
            return int(row["id"])
    return None
```

Валидация/подготовка (в `validate()` или при первом `parse_batch`):
- получить `spectra_files = await self.project.get_spectra_files()` (все);
- построить `self.ms_run_spectra: dict[int, int]` по
  `self.ms_run_locations`; неразрешённые — warning;
- если `self.spectra_file_id` задан и ровно один `ms_run` — использовать
  его (п. 0.5, Q16).

Схлопывание белков: группировка строк PSM по `PSM_ID` (+ `spectra_ref`),
accession'ы уникально join'ятся `;`, остальные поля — first. Аналогично
PLGS `prepare_df`. Затем `src_file_protein_id` разбивается по `;` и
создаются `Protein(id=accession, is_uniprot=self.is_uniprot_proteins)`
(dedup по accession), как в `SimpleTableImporter.get_proteins`.

Важно: схлопывание выполняется **до** батчинга, чтобы не плодить
дубликаты идентификаций на один спектр.

### 3.7. `parse_batch` — выход

Колонки выходного DataFrame:

| Колонка | Примечание |
|---|---|
| `scans` **или** `seq_no` | по `self.spectra_id_field` |

| `canonical_sequence` | bare |
| `score` | float \| None |
| `ppm` | float \| None |

- каноническая — из residue'ов ProForma;
- `opt_global_aa_scores` **кладём** в `positional_scores` (список float,

```python
class CasaNovoImporter(MzTabImporter):
    PARSER_ID = "CasaNovo"
    contain_proteins = False
    can_import_multifile = False
    spectra_id_field = "seq_no"

    PROFORMA_COL = "opt_global_cv_MS:1003169_proforma_peptidoform_sequence"
    AA_SCORES_COL = "opt_global_aa_scores"

    def get_modified_sequence(self, seq: str, mods: str) -> str:
        return seq  # значение из PROFORMA_COL передаётся как есть

    def get_canonical_sequence(self, row: dict) -> str:
        return "".join(aa for aa, _ in parse(row[self.PROFORMA_COL])[0])
```

В переопределённом маппинге строки: `sequence ← row[PROFORMA_COL]`,

(если колонка не-null), `modifications` не читается.

Прочее (резолв `seq_no`, ppm, score) наследуется.

### 5.1. Преобразование `prediction`

Порядок (подтверждён): (1) `BS/BT/BY` → `S/T/Y[Phospho]`,
(2) удалить одиночный `B` перед не-S/T/Y, (3) массовые замены. N-терминальные
замены применяем **везде** (пересечений не предполагается).

```python
_PHOSPHO_B = re.compile(r"B([STY])")

_REPLACES = {
    # N-terminal
    "[+43.006-17.027]": "[Carbamyl][Ammonia-loss]-",
    "[+42.011]":        "[Acetyl]-",
    "[+43.006]":        "[Carbamyl]-",
    "[-17.027]":        "[Ammonia-loss]-",
    # аминокислотные
    "[+57.021]":        "[Carbamidomethyl]",
    "[+15.995]":        "[Oxidation]",
    "[+0.984]":         "[Deamidated]",
}

@classmethod
def transform_sequence(cls, raw: str) -> str:
    s = cls._PHOSPHO_B.sub(r"\1[Phospho]", raw)
    s = re.sub(r"B(?=[A-Z])", "", s)      # одиночный B-артефакт
    for src, dst in cls._REPLACES.items():
        s = s.replace(src, dst)
    return s
```

Проверка примера: `BSPRPDSPHDC[+57.021]YC[+57.021]AK` →
`s = S[Phospho]PRPDSPHDC[+57.021]YC[+57.021]AK` →
замены → `S[Phospho]PRPDSPHDC[Carbamidomethyl]YC[Carbamidomethyl]AK`
(корректная ProForma).

### 5.2. `transform_df`

```python
def transform_df(self, df):
    df = df.copy()
    df["prediction"] = df["prediction"].apply(self.transform_sequence)
    df["label"] = df["label"].astype(str).str.strip().str.lower()   # title
    return df
```

`canonical_sequence` в `ColumnRenames` не задаём (Pi-PrimeNovo не даёт
исходную каноническую). Проблема: `SimpleTableImporter` не умеет
вычислять `canonical_sequence` из ProForma. Вариант: в
`transform_df` добавить колонку `canonical_sequence` и замапить её в
`renames` через фиктивное исходное имя (напр.
`canonical_sequence="canonical_sequence"`):

```python
renames = ColumnRenames(
    title="label",
    sequence="prediction",
    canonical_sequence="canonical_sequence",
    score="score",
)
...
df["canonical_sequence"] = df["prediction"].apply(
    lambda s: "".join(aa for aa, _ in parse(s)[0])
)
```

(Порядок в `transform_df`: сначала `transform_sequence`, потом
`canonical_sequence` из уже преобразованной строки.)

## 7. Known issues / риски

1. **PSI-MOD / CHEMMOD в ion match и графиках** — другая библиотека
   менее всеядна; возможны сбои отрисовки/расчёта массы. Осознанно
   принимаем (Q23).
2. **Unimod требует сеть** — при отсутствии сети парсинг mzTab без
   MTD-имён (режим offline) выполнится с ошибкой. Отдельная доработка
   в перспективе (Q22).
3. **Несколько ms_run в одном файле PD** — `spectra_id_field`
   определяется по первой строке; смешение `scan=`/`index=` в одном
   файле не поддерживается (warning).
4. **Порядок инициализации PTM** — merge на старте GUI должен идти
   раньше импорта модулей, кэширующих `PTMS` (§2.2, §2.4).
5. `PROJECT_VERSION`, `APP_VERSION`, `__version__`, `pyproject.toml`,
   `dasmixer.iss` **агентом не меняются** (только скрипт сборки).
