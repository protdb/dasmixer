# 0.7.5a1 дополнительные параметры protein match и file name в импорте MGF.

В этой версии поднимаем PROJECT_VERSION до 0.7.5 и реализуем миграции до этой версии

## Расширение схемы:

- таблица spectre:
  - добавляется поле file_name TEXT, создаётся индекс для этого поля
- таблица identification:
  - добавляется поле source ppm, бэкап исходного значения PPM если было исправление при пересчёте
- таблица peptide_match:
  - добавляются поля по аналогии с identification:
    - lcrr
    - unconfirmed_ptms
    - quality
