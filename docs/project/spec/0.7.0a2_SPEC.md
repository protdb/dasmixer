**Версия:** 0.7.0a2  
**Дата:** 2026-07-13  
**Статус:** ФИНАЛЬНАЯ — готова к реализации

---

## 1. Контекст и проблема

При экспорте MGF из DASMixer теряется большая часть метаданных исходного спектра. Поле `all_params` (таблица `spectre`) содержит полный словарь заголовков исходного MGF-файла, но `_build_spectrum_params()` игнорирует его и строит заголовок с нуля — только `title`, `pepmass` (без интенсивности) и `charge`.

**Что теряется сейчас:**

| Потеря | Причина |
|---|---|
| `INSTRUMENT=ESI-TRAP` и другие произвольные MGF-ключи | `all_params` не используется |
| Интенсивность в строке `PEPMASS=... <intensity>` | `spec_row["intensity"]` игнорируется |
| `RTINSECONDS=...` | не берётся из `all_params` |
| `SCANS=...` | поле `spec_row["scans"]` не выводится |
| Заряд на каждый пик (третья колонка пиков) | `charge_array_common_value` не используется |
| Комментарий о происхождении файла | отсутствует |

---

## 2. Требования

1. Восстановить дополнительные поля из `all_params` (`instrument`, `rtinseconds` и т.п.) в заголовок MGF.
2. Восстановить интенсивность прекурсора: `PEPMASS=<mass> <intensity>` — из `spec_row["intensity"]`.
3. Восстановить заряд на каждый пик (третья колонка).
4. `charge` в заголовке — из `spec_row["charge"]` (int). При `write_spectra_charge=True` и наличии идентификации — перезаписать из `ident["override_charge"]`.
5. `SCANS` fallback: если `scans` отсутствует в `all_params` — писать `spec_row["scans"]` из БД.
6. `SEQ` при `write_seq=True` — перезаписать из идентификации. Если идентификации нет — оставить `all_params["seq"]` (если был). Если `write_seq=False` — `seq` из `all_params` остаётся как есть.
7. Первая строка каждого MGF-файла: `# Exported from DASMixer` — для всех форматов сжатия.

## 3. Данные (из диагностики на реальном проекте)

Пример реального `all_params` (PLGS-спектры):
```json
{
  "mass": "Monoisotopic",
  "_spectrum_type": "Electrospray-Shotgun",
  "instrument": "ESI-TRAP",
  "pepmass": [817.3723, 1398.0],
  "charge": [1],
  "title": "LEPeakID:1:_AVERAGE_CHARGE=1.0:_DRIFT_TIME_IN_BINS=95.05456",
  "rtinseconds": 68.50712
}
```

Поле `scans` в `all_params` **отсутствует** (PLGS не пишет его напрямую), но присутствует в `spec_row["scans"]` (заполняется из TITLE при импорте через regex `lepeakid:(\d+):`).

Поле `charge_array` = `None` при `charge_array_common_value = 1` — нужна реконструкция через `np.full`.

## 5. Задачи реализации

### Задача 1. Рефакторинг `_build_spectrum_params()`

Полностью переписать тело функции. Сигнатура не меняется.

**Алгоритм:**

```python
def _build_spectrum_params(spec_row, ident, write_offset, write_spectra_charge, write_seq, seq_type):

    # Ключи из all_params, которые обрабатываются явно — не копировать автоматически
    EXPLICIT_KEYS = {"mass", "charge", "pepmass", "title", "scans", "seq"}
    # Ключи с префиксом "_" — внутренние pyteomics, не копировать

    params = {}

    # 1. Дополнительные поля из all_params (только "чужие" ключи)
    all_params = spec_row.get("all_params") or {}
    for key, value in all_params.items():
        if key.startswith("_"):
            continue
        if key in EXPLICIT_KEYS:
            continue
        params[key] = value
    # Результат: в params попадает, например, {"instrument": "ESI-TRAP", "rtinseconds": 68.507}

    # 2. title — из поля БД
    params["title"] = spec_row.get("title", "")

    # 3. pepmass — масса + интенсивность прекурсора
    mass = spec_row.get("pepmass", 0.0)
    intensity = spec_row.get("intensity")   # REAL, может быть None
    params["pepmass"] = (float(mass), float(intensity) if intensity is not None else None)

    # 4. charge — из поля БД (INTEGER), опционально переопределяется из идентификации
    charge = spec_row.get("charge")         # int или None
    if write_spectra_charge and ident is not None:
        override = ident.get("override_charge")
        if override is not None:
            charge = int(override)
    if charge is not None:
        params["charge"] = [int(charge)]    # MGF-формат: список интов

    # 5. scans — fallback из БД если нет в all_params
    scans_in_all_params = all_params.get("scans")
    if scans_in_all_params is not None:
        params["scans"] = scans_in_all_params
    else:
        scans_from_db = spec_row.get("scans")
        if scans_from_db is not None:
            params["scans"] = int(scans_from_db)

    # 6. seq
    if write_seq and ident is not None:
        seq_val = ident.get("canonical_sequence" if seq_type == "canonical" else "sequence") or ""
        if seq_val:
            params["seq"] = seq_val
    else:
        seq_in_all_params = all_params.get("seq")
        if seq_in_all_params:
            params["seq"] = seq_in_all_params

    # 7. offset (логика без изменений)
    if write_offset and ident is not None:
        offset_val = ident.get("isotope_offset")
        if offset_val is not None:
            params["offset"] = offset_val

    return params
```

### Задача 2. Восстановление `charge array` пиков

**Файл:** `mgf_export.py`, функция `_write_mgf_to_file()`

В начало функции добавить `import numpy as np` (или в топ файла).

В теле цикла, после получения `mz_arr`:

```python
# Восстановить charge array для пиков
charge_arr = full_spec.get("charge_array")      # numpy float array или None
if charge_arr is None:
    common_val = full_spec.get("charge_array_common_value")   # int или None
    if common_val is not None and mz_arr is not None:
        charge_arr = np.full(len(mz_arr), float(common_val))

# Формировать dict спектра
spectrum_dict = {
    "params": params,
    "m/z array": mz_arr,
    "intensity array": int_arr,
}
if charge_arr is not None:
    spectrum_dict["charge array"] = charge_arr

batch_spectra.append(spectrum_dict)
```

## 7. Тестирование (ручное)

1. Открыть проект с PLGS-спектрами, экспортировать MGF (режим "All", сжатие "None").
2. Проверить:
   - Первая строка файла: `# Exported from DASMixer`
   - `INSTRUMENT=ESI-TRAP` присутствует
   - `PEPMASS=<mass> <intensity>` — два числа через пробел
   - `RTINSECONDS=...` присутствует
   - `SCANS=<n>` присутствует (значение из БД)
   - Пики имеют третью колонку (`1.0`)
3. Проверить `write_seq=True`:
   - Спектр с идентификацией → `SEQ=<из идентификации>`
   - Спектр без идентификации → поле SEQ отсутствует (нет в `all_params` у PLGS)
4. Проверить все режимы сжатия — комментарий присутствует.
5. Проверить `write_spectra_charge=True` с идентификацией, имеющей `override_charge` — заряд в `CHARGE=` должен быть из идентификации.
