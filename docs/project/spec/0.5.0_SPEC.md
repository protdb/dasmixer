## 1. Цель и ограничения

### Цель
Разбить монолитный пакет `dasmixer` на четыре пакета, распространяемых через PyPI независимо, при этом сохранив монорепозиторий и синхронную разработку.

### Ограничения
- **Монорепозиторий**: всё остаётся в одном git-репозитории; разработка ведётся синхронно из единой директории.
- **Namespace Package (PEP 420)**: все пакеты вносят вклад в общее пространство имён `dasmixer`. Ни в одной из директорий `src/dasmixer/` не должно быть `__init__.py`.
- **Минимальные изменения структуры**: импортные пути в коде (`dasmixer.api.*`, `dasmixer.gui.*`, `dasmixer.cli.*`) не меняются.
- **Синхронное версионирование**: все пакеты версии `0.5.0`; зависимости между ними строго `==0.5.0`.
- **dasmixer.spec** остаётся в корне репозитория, не меняется.
- Сборка под Windows (`dasmixer.spec`) только для полного приложения (`metapackage`).

```python
# dasmixer/api/reporting/report_form.py
"""Abstract base for report parameter forms (no flet dependency)."""
import json
import copy
from abc import abstractmethod
from typing import TYPE_CHECKING

if TYPE_CHECKING:
    from dasmixer.api.project.project import Project


class ReportParamBase:
    """Abstract base for a single report parameter."""
    def __init__(self, label: str | None = None, default=None):
        self.label = label
        self.default = default
        self._attr_name: str | None = None

    def get_value(self):
        """Return current value in native Python type."""
        return self.default

    def set_value(self, value) -> None:
        self.default = value


class ReportFormMeta(type):
    """Metaclass: collects ReportParamBase fields declared in the class body."""
    def __new__(mcs, name, bases, namespace):
        field_defs: dict[str, ReportParamBase] = {}
        for key, val in list(namespace.items()):
            if isinstance(val, ReportParamBase):
                field_defs[key] = val
        namespace['_field_defs'] = field_defs
        return super().__new__(mcs, name, bases, namespace)


class ReportForm(metaclass=ReportFormMeta):
    """
    Base class for typed report parameter forms.
    Core-side: handles values only (no flet builds).
    GUI-side subclass adds build() and get_container().
    """
    _field_defs: dict[str, ReportParamBase]

    def __init__(self, project: "Project"):
        self.project = project
        self._fields: dict[str, ReportParamBase] = {}
        for attr_name, field_def in self._field_defs.items():
            field_copy = copy.copy(field_def)
            field_copy._attr_name = attr_name
            if field_copy.label is None:
                field_copy.label = attr_name.replace('_', ' ').title()
            self._fields[attr_name] = field_copy

    def get_values(self) -> dict:
        return {name: field.get_value() for name, field in self._fields.items()}

    def set_values(self, values: dict) -> None:
        for name, val in values.items():
            if name in self._fields:
                self._fields[name].set_value(val)

    def to_json(self) -> str:
        return json.dumps(self.get_values())

    @classmethod
    def from_json_str(cls, json_str: str, project: "Project") -> "ReportForm":
        instance = cls(project)
        try:
            values = json.loads(json_str)
            for name, val in values.items():
                if name in instance._fields:
                    instance._fields[name].default = val
        except Exception:
            pass
        return instance
```

```python
# dasmixer/gui/main.py
"""GUI entry point: команда `dasmixer`."""
import multiprocessing
import typer
from pathlib import Path
from typing import Annotated

from dasmixer.versions import APP_VERSION

# Настройка логирования
try:
    from dasmixer.api.config import config as _app_config
    from dasmixer.gui.views.settings_view import _apply_logging_config
    _apply_logging_config(_app_config)
except Exception as e:
    print(f"[Logging] {e}")

# Загрузка плагинов
try:
    from dasmixer.api.plugin_loader import load_identification_plugins, load_report_plugins
    _plugin_load_results = load_identification_plugins() + load_report_plugins()
    _plugin_errors = [r for r in _plugin_load_results if r.get("error")]
    for r in _plugin_errors:
        print(f"[Plugin warning] '{r['id']}': {r['error']}")
except Exception as e:
    _plugin_load_results = []
    print(f"[Plugin loader] {e}")

# Привязка GUI-форм к отчётам (monkey-patch)
import dasmixer.gui.reports.forms  # noqa: F401

app = typer.Typer(name="dasmixer", add_completion=False)


@app.callback(invoke_without_command=True)
def main(
    ctx: typer.Context,
    file_path: Annotated[str | None, typer.Argument(
        help="Path to .dasmix project (opens in GUI). Creates if not exists."
    )] = None,
    version: Annotated[bool, typer.Option("--version", "-v")] = False,
):
    """DASMixer — запустить GUI (опционально с файлом проекта)."""
    if version:
        typer.echo(f"DASMixer {APP_VERSION}")
        raise typer.Exit(0)
    if ctx.invoked_subcommand is None:
        from dasmixer.gui.app import run_gui
        run_gui(file_path)


if __name__ == '__main__':
    multiprocessing.freeze_support()
    _ensure_chrome()
    app()
```

Функция `_ensure_chrome()` переносится из `dasmixer/main.py` в `dasmixer/gui/main.py` без изменений.

> **Поведение при несуществующем файле**: логика `run_gui(file_path)` — существующая; если файл не существует, GUI создаёт новый проект. Это поведение не меняется.

```python
# dasmixer/cli/main.py
"""CLI entry point: команда `dasmixer-cli`."""
import typer
from typing import Annotated
from pathlib import Path

from dasmixer.versions import APP_VERSION
from dasmixer.cli.commands import project, subset, import_data

app = typer.Typer(name="dasmixer-cli", add_completion=False)


@app.callback(invoke_without_command=True)
def main(
    ctx: typer.Context,
    version: Annotated[bool, typer.Option("--version", "-v")] = False,
):
    """DASMixer CLI — управление проектами без GUI."""
    if version:
        typer.echo(f"DASMixer CLI {APP_VERSION}")
        raise typer.Exit(0)
    if ctx.invoked_subcommand is None:
        typer.echo(ctx.get_help())


app.add_typer(project.app, name="create")
app.add_typer(subset.app, name="subset")
app.add_typer(import_data.app, name="import")

if __name__ == '__main__':
    app()
```

## 7. `pyproject.toml` — ключевые детали для Poetry

### Namespace Packages в Poetry

В каждом подпакете `[tool.poetry]` явно перечисляет включаемые директории:

```toml
# dasmixer-core/pyproject.toml
[tool.poetry]
packages = [
    {include = "dasmixer/api", from = "src"},
    {include = "dasmixer/utils", from = "src"},
    {include = "dasmixer/versions.py", from = "src"},
]

# dasmixer-gui/pyproject.toml
[tool.poetry]
packages = [
    {include = "dasmixer/gui", from = "src"},
]

# dasmixer-cli/pyproject.toml
[tool.poetry]
packages = [
    {include = "dasmixer/cli", from = "src"},
]
```

> **Критично**: в директории `src/dasmixer/` не должно быть `__init__.py` ни в одном из пакетов. Файлы `src/dasmixer/api/__init__.py`, `src/dasmixer/gui/__init__.py`, `src/dasmixer/cli/__init__.py` — существуют (это нормальные пакеты внутри namespace).

## 8. Скрипт сборки `build_all.sh`

**Расположение**: корень репозитория (`/home/gluck/PycharmProjects/dasmixer/build_all.sh`).  
**Платформа**: только Linux/bash.

### Алгоритм скрипта

```
1. Проверить наличие `poetry`, `twine` в PATH
2. Для каждого пакета (dasmixer-core, dasmixer-gui, dasmixer-cli, metapackage):
   a. cd в директорию пакета
   b. `poetry build` → создаёт ./dist/*.whl и *.tar.gz
   c. Проверить exit code, выйти если ошибка
3. Вывести список созданных артефактов (все dist/*)
4. Запросить подтверждение: "Upload to TestPyPI? [y/N]"
5. При подтверждении: `twine upload --repository testpypi <all artifacts>`
6. Вывести ссылки на TestPyPI для проверки
7. Запросить подтверждение: "Upload to PyPI (PRODUCTION)? [y/N]"
8. При подтверждении: `twine upload <all artifacts>`
9. Финальный отчёт
```

### Псевдокод скрипта

```bash
#!/usr/bin/env bash
set -euo pipefail

PACKAGES=("dasmixer-core" "dasmixer-gui" "dasmixer-cli" "metapackage")
REPO_ROOT="$(cd "$(dirname "$0")" && pwd)"
ALL_DISTS=()

echo "=== DASMixer Build Script ==="

# Step 1: Check dependencies
command -v poetry >/dev/null 2>&1 || { echo "ERROR: poetry not found"; exit 1; }
command -v twine  >/dev/null 2>&1 || { echo "ERROR: twine not found. pip install twine"; exit 1; }

# Step 2: Build all packages
for pkg in "${PACKAGES[@]}"; do
    echo "--- Building $pkg ---"
    PKG_DIR="$REPO_ROOT/$pkg"
    (cd "$PKG_DIR" && poetry build)
    while IFS= read -r f; do ALL_DISTS+=("$f"); done < <(find "$PKG_DIR/dist" -name "*.whl" -o -name "*.tar.gz")
done

echo ""
echo "=== Built artifacts ==="
for f in "${ALL_DISTS[@]}"; do echo "  $f"; done

# Step 3: TestPyPI
read -rp $'\nUpload to TestPyPI? [y/N] ' confirm
if [[ "$confirm" =~ ^[Yy]$ ]]; then
    twine upload --repository testpypi "${ALL_DISTS[@]}"
    echo ""
    echo "TestPyPI links:"
    for pkg in "${PACKAGES[@]}"; do
        PKG_NAME=$(cd "$REPO_ROOT/$pkg" && poetry version | awk '{print $1}')
        echo "  https://test.pypi.org/project/$PKG_NAME/"
    done
fi

# Step 4: Production PyPI
read -rp $'\nUpload to PyPI (PRODUCTION)? [y/N] ' confirm2
if [[ "$confirm2" =~ ^[Yy]$ ]]; then
    twine upload "${ALL_DISTS[@]}"
    echo "Done."
fi
```

## 13. Замечания и риски

### Риск 1: Poetry и namespace packages
Poetry `packages = [{include = "dasmixer/api", from = "src"}]` может требовать тонкой настройки. Если `poetry build` кладёт файлы неправильно — проверить через `pip show -f dasmixer-core` после установки.

### Риск 2: Monkey-patching форм отчётов
`PCAReport.parameters = PCAForm` в `gui/reports/forms.py` выполняется при первом импорте модуля. Важно, чтобы этот импорт происходил ДО того, как GUI начнёт рендерить вкладку Reports. Гарантируется строкой `import dasmixer.gui.reports.forms` в `gui/main.py`.

### Риск 3: Плагины с зависимостью от ReportForm
Сторонние плагины отчётов, написанные пользователями, могут импортировать `from dasmixer.gui.components.report_form import ReportForm`. Это продолжит работать при наличии `dasmixer-gui`. Ничего не ломается.

### Риск 4: Circular imports
После перемещения `report_form.py` в core и наследования в gui: важно убедиться, что `dasmixer.api.reporting.report_form` не импортирует ничего из `dasmixer.gui.*`. Текущий `TYPE_CHECKING` блок в `base.py` это обеспечивает.

### Риск 5: `dasmixer/__init__.py` и `__version__`
После удаления `dasmixer/__init__.py` код `import dasmixer; dasmixer.__version__` перестанет работать. Если где-то используется — нужно заменить на `from dasmixer.versions import APP_VERSION`. Проверить через `grep -r "dasmixer.__version__"`.
